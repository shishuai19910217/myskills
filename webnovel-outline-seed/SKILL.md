# 小说大纲摘要生成器（webnovel-outline-seed）

> **定位**：从 0 到故事骨架。在零灵感 / 弱灵感 / 有明确偏好三种状态下，产出对齐目标平台（番茄/七猫）爆款赛道、具备完整三幕展开潜力的故事种子与大纲摘要，并可持续迭代。
> **使用对象**：网文作者、编辑、零灵感用户，想从零搭故事骨架的人。
> **与既有 skill 的关系**（前置环节，独立运行）：
> - 本 skill：**写之前**——从 0 产出种子 + 三幕大纲摘要；
> - `webnovel-quality-check`：**写之后**——检查"故事讲得好不好"（22 大类叙事缺陷）；
> - `webnovel-reading-health-check`：**写之后**——检查"读者会不会追读"；
> - `webnovel-deai-lint`：**写之后**——检查"有没有 AI 味"。
> **版本**：v1.0.0（对应规格 v1.01；平台规则版本见附录A）
> **维护**：改版前自查见附录B。

## 一、技能定位

### 名称与触发词

- **名称**：小说大纲摘要生成器（webnovel-outline-seed）
- **触发词**：小说大纲、故事种子、没有灵感、想写小说不知道写什么、三幕大纲、番茄/七猫开篇、故事骨架、灵感扩写、"随便写个故事"

### 核心目标

让用户在**零输入 / 弱输入 / 有明确偏好**三种状态下，都能拿到三样东西：

1. **3 个可挑选的故事种子**（每个都是含 主角+欲望+阻力+代价 的完整微型故事前提）；
2. **选中后的完整三幕大纲摘要**（一次性输出，含平台节奏检查）；
3. **9 个可修改旋钮**（持续迭代，不推倒重来）。

全程对齐目标平台爆款赛道，不生成平台已验证"踩雷"的类型。

### 适用对象

网文作者、编辑、零灵感用户、AI 辅助创作、短剧定制文作者。

### 不适用

1. **章节正文生成 / 逐章细化**（本 skill 到大纲摘要为止）；
2. **已有完整大纲、只需质量审查** → 应走 `webnovel-quality-check` / `webnovel-reading-health-check`；
3. **正文 AI 味检测** → 应走 `webnovel-deai-lint`；
4. **实时平台数据抓取 / 投稿自动化**；
5. **诗歌、非叙事类、非中文网文平台**（赛道规则只覆盖番茄/七猫）。

---

## 二、总原则（11 条，全流程不可违背）

1. 用户零输入时，**不追问、不拖延**，直接随机生成故事种子。
2. 用户有输入时，把输入当作**软约束**，而不是硬限制。
3. 先交付可挑选的"故事种子/核心冲突"，**再**展开成大纲摘要。
4. 每个种子必须是**已包含 主角、欲望、阻力、代价**的完整微型故事前提。
5. 默认只生成 **3 个**种子，少量但深挖，每个都具备完整三幕展开潜力。
6. 种子之间必须有明显差异：题材、情感、结局倾向、冲突类型**至少两项不同**。
7. 筛选种子时：**内在戏剧张力是硬门槛，可展开性是排序与验证标准，差异性用于最终搭配**。
8. 用户选中种子后，**一次性**输出完整三幕大纲摘要。
9. 大纲摘要采用"**固定字段为骨架，允许类型化变体**"。
10. 输出大纲后，主动附带"**可修改旋钮**"，让用户继续迭代。
11. **所有种子和展开内容必须对齐目标平台的爆款赛道逻辑，不能生成平台已验证"踩雷"的类型。**

## 三、六层系统总览

```
输入
  │
  ▼
[平台层]   确定平台（默认番茄）+ 注入赛道约束（附录A）
  │
  ▼
[输入层]   判定输入状态：零输入 / 弱输入 / 有明确偏好
  │
  ▼
[种子层]   生成 3 个种子（12 字段）→ 过 3 道硬闸门 → 暂停等选择
  │
  ▼
[选择层]   用户选一个；"随便"时自动代选
  │
  ▼
[展开层]   一次性输出完整三幕大纲摘要（12 必填硬字段 + 类型化变体 + 平台节奏检查）
  │
  ▼
[迭代层]   附 9 个可修改旋钮，循环迭代直至用户满意
```

**执行顺序固定**，不可跳层、不可调换。

## 四、平台层：赛道匹配

### 第 1 步：确定目标平台

- 用户指定"七猫"或"番茄" → 按对应平台规则运行；
- 用户**未指定平台** → 默认按**番茄小说**处理，并在输出中标注"按番茄规则运行"；
- 平台名模糊 / 其它平台 → 默认番茄，标注"按番茄规则运行"。

### 第 2 步：按平台注入赛道约束

平台规则是**静态高信息密度资源**，完整赛道清单、避雷区、节奏规则见**附录A**。执行前**必须加载对应平台的全部规则**（安全赛道、避雷区、结构要求、新兴方向），并在内存中打执行标记：

- 种子字段 2「目标平台与赛道标签」必须落在有效赛道内；
- 种子字段 12「平台适配验证」必须**逐条核对避雷区**显式回答；
- 展开层字段 12「平台节奏检查」必须执行附录A 的平台节奏规则。

**平台合规是硬约束**：任何种子或展开内容踩中附录A 避雷区 → 立即重写，不得输出。

## 五、输入层：状态判定

| 输入特征 | 判定 | 处理 |
|---|---|---|
| 空输入 / 只有平台选择 | **零输入** | 直接进种子层，不追问、不要求补全 |
| 模糊情绪（如"想写个压抑的""要爽的"） | **弱输入** | 直接进种子层；情绪作为软约束注入种子倾向，不要求补全 |
| 一句灵感（如"外卖员重生"） | **弱输入** | 作为软约束注入；可覆盖种子题材倾向，但不锁定全部 |
| 明确偏好（题材/平台/结局倾向等） | **有明确偏好** | 生成 3 个种子并说明"如何吸收该偏好 + 如何对齐平台赛道" |

> **弱输入处理原则**：软约束**只做加权，不做过滤**——只影响种子排序与倾向，不淘汰掉与之不同的种子（保住差异性）。

## 六、种子层：生成 3 个故事种子

### 6.1 每个种子输出 12 个字段

```
种子 N · 标题：<...>

1. 目标平台与赛道标签：<必须对齐附录A 有效赛道>
2. 一句话前提：<完整微型故事前提>
3. 主角：
   - 身份：<...>
   - 初始状态：<...>
   - 缺陷或执念：<...>
4. 欲望：
   - 外在目标：<...>
   - 内在需求：<...>
5. 阻力：
   - 主要对抗力量：<...>
   - 为什么不可调和：<...>
6. 代价：
   - 失败会失去什么：<...>
   - 成功也要付出什么：<...>
7. 核心冲突：<一句话说清不可调和的对撞>
8. 三幕潜力：
   - 第一幕钩子：<...>
   - 第二幕升级：<...>
   - 第三幕高潮方向：<...>
9. 可能的高潮：<主角必须做出的不可逆选择>
10. 可能的结局：
    - 外部结局：<...>
    - 内在结局：<...>
11. 平台适配验证：<是否对齐爆款赛道？是否避开避雷区？显式回答>
```

### 6.2 生成流程：3 道硬闸门（按序执行，不可调换）

```
生成候选池（≥3 个）
  → [闸门1·张力硬门槛]
      主角欲望 vs 阻力是否直接对撞？代价是否不可逆？冲突能否升级？
      任一不达标 → 回炉重写该种子（不做"降级保留"）
  → [闸门2·可展开性排序]
      能否自然长出三幕转折、高潮与结局？
      对通过闸门1的种子按可展开性从高到低排序
  → [闸门3·差异性定搭配]
      题材 / 情感 / 结局倾向 / 冲突类型 ≥2 项不同
      取差异最大的 3 个为最终输出
  → 输出 3 个种子 → 暂停，等待用户选择
```

> **闸门顺序依据总原则 7**：张力=硬门槛（一票否决）；可展开性=排序验证；差异性=最终搭配。三者不可并列、不可调换。

### 6.3 暂停规则

- 种子输出后**必须暂停**，等待用户选择或"随便"指令；
- **不得**在种子层直接展开大纲；
- 用户说"随便 / 你选一个" → 按下一层规则自动代选。

## 七、选择层

- 用户选中一个种子 → 进入展开层；
- 用户说"随便 / 你选一个" → 替其选**张力最强 → 三幕最完整 → 平台适配度最高**的种子。

## 八、展开层：一次性输出完整三幕大纲摘要

### 8.1 必填 12 硬字段

```
【完整三幕大纲摘要】

1. 一句话前提：<...>
2. 主角：<...>
3. 欲望：<...>
4. 阻力：<...>
5. 代价：<...>
6. 第一幕：
   - 目标：<...>
   - 冲突：<...>
   - 转折点：<...>
7. 第二幕：
   - 目标：<...>
   - 冲突：<...>
   - 中点反转：<...>
   - 低谷：<...>
   - 转折点：<...>
8. 第三幕：
   - 目标：<...>
   - 冲突：<...>
   - 高潮：<...>
   - 结局：<...>
9. 高潮：<主角必须做出的不可逆选择>
10. 结局：
    - 外部结局：<...>
    - 内在结局：<...>
11. 主题余韵：<故事在追问什么>
12. 平台节奏检查：<开篇钩子是否符合目标平台的黄金三章逻辑？逐条对照附录A 节奏规则>
```

### 8.2 可选类型化变体字段（按种子类型自适应加入）

- 世界观规则（奇幻/科幻/玄幻）
- 关键配角
- 反派逻辑
- 类型标签
- 情感曲线（言情）
- 时间线（重生/穿越/时间循环）
- 叙事视角
- 象征意象
- **短剧适配度评估**（目标平台有短剧改编方向时——七猫短剧定制文赛道必带）

### 8.3 平台节奏附加要求（执行前加载附录A 对应平台节奏规则）

- **番茄平台**：开篇 300 字内必须出现核心冲突或强钩子；每 3 章至少一个情绪释放点；避免慢热铺垫。
- **七猫平台**：离婚文注意"离婚倒计时"开局吸引力；甜宠文遵循"3-5-8"节奏法；情绪拉扯必须足够强。

### 8.4 展开层硬纪律

1. **一次性输出**完整三幕大纲，不做分步确认；
2. 每个转折必须由前文**因果逼出**，不能机械拼接（生成时自问"这个转折的上一个原因是什么"）；
3. 高潮必须解决核心冲突，并让主角付出代价；
4. 结局必须回应主题余韵；
5. 语言具体，避免空泛套话。

## 九、迭代层：主动附带可修改旋钮

### 9.1 九个旋钮

```
【可修改旋钮】请选择要调整的项（可多选）：

1. 结局倾向：光明 / 苦涩 / 开放 / 悲剧 / 救赎
2. 主角道德立场：善良 / 灰色 / 反英雄 / 反派
3. 冲突烈度：日常 / 生死 / 世界存亡 / 心理
4. 叙事视角：第一人称 / 第三人称限知 / 全知 / 多视角
5. 类型切换：奇幻 / 科幻 / 悬疑 / 言情 / 现实等
6. 情感基调：希望 / 压抑 / 荒诞 / 温柔 / 冷峻
7. 节奏：紧凑 / 史诗 / 慢燃
8. 平台切换：番茄 ↔ 七猫（切换后需重新适配赛道约束）
9. 赛道微调：在当前平台内换一个细分方向
```

### 9.2 迭代铁律

- 用户提出修改 → **只调整被旋钮命中的维度，其余锁定**；
- 保持人物、因果与主题**连贯**；
- **不推倒重来**，除非用户明确要求"重新生成"；
- 平台切换（旋钮 8）与赛道微调（旋钮 9）后必须**重新执行平台适配验证**（重新对照附录A 对应平台规则）。

### 9.3 循环终止条件

- 用户明确表示满意 / 进入下一步（如去写正文、去质量检查）；
- 用户要求重建 → 回到种子层重新生成（保留已选平台的赛道约束）。

### A.1 番茄小说 2026 爆款赛道规则

#### 男频安全赛道（优先级从高到低）

1. **都市/神豪/脑洞类**——流量最稳。核心是"爽"，热门标签：神豪、系统、重生、脑洞。2026年核心逻辑是"脑洞破圈、情绪拉满"[reference:0]。
2. **重生/穿越/逆袭类**——核心逻辑是"弥补遗憾"和"改变命运"。开篇直接写主角临死前的悔恨然后重生，留存率极高[reference:1]。
3. **专业流+生活流**——读者看腻了无敌流，现在最硬核的金手指是专业知识。如《律师：开局把对方法官送进去》《文物修复师：直播补全〈兰亭序〉》。爽感来源是"降维打击的智力优越感"[reference:2]。

#### 女频安全赛道

- **闪婚/霸总/追妻火葬场** + "马甲+萌宝+先婚后爱"混合体。核心逻辑：情绪价值拉满。趋势是"男主跪着追妻"而非古早霸总[reference:3]。
- **无CP大女主**——2025网文十大关键词之一，读者对剥离情感依附、专注自我成长的渴望愈加强烈[reference:4]。

#### 番茄 2026 避雷区（不得生成）

- 传统都市重生文[reference:5]
- 流水线真假千金文[reference:6]
- 无脑甜宠文[reference:7]
- 传统玄幻+纯金手指开挂流[reference:8]

#### 番茄爆款结构要求

- 开篇代入感强、主线清晰、人物立得住。番茄45岁以上活跃用户占比45.7%，不要只盯着年轻人写[reference:9]。
- 读者要的不是"主角很强"，是"主角的烦恼我有，主角的破局方法我能学"[reference:10]。

#### 番茄新兴高潜力方向（可作为差异种子使用）

- 都市高武（如《我不是戏神》，反转密集、高能不断）[reference:11]
- 悬疑+人性博弈（如《十日终焉》，逻辑严谨、环环相扣）[reference:12]
- 短篇赛道：都市男频、职场商战、三农议题快速起量，2万字以上中短篇爆款IP增长300%[reference:13]。

#### 番茄节奏硬约束

- 开篇 300 字内必须出现核心冲突或强钩子；
- 每 3 章至少有一个情绪释放点；
- 避免慢热铺垫。

### A.2 七猫小说 2026 爆款赛道规则

#### 2026 重点收稿方向（七猫第八届作者大会明确）

- 东方玄幻、架空历史、宫闱宅斗、玄幻仙侠四大品类重点加码[reference:14]。
