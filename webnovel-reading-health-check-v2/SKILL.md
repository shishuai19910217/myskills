# 小说追读体检器 v2（webnovel-reading-health-check-v2）

> **定位**：追读视角的叙事健康诊断。标出影响读者"愿意继续读下去"的体感、逻辑、合理、时空问题，以及承诺兑现、道德情绪报偿、角色情感锚点、追读目标与连载阶段错配问题，按优先级给修复处方；默认只诊断不改写。
> **使用对象**：小说作者、编辑、网文写手、AI 辅助审稿、剧本/故事检查。
> **与既有 skill 的关系**：
> - `webnovel-reading-health-check`（v1.0）：本 skill 的前代版本，保留并行可用；
> - 本 skill（v2.0）：在 v1 基础上整合圆桌勘探成果（36 条边界约束），新增承诺链、道德情绪报偿、角色情感锚点、目标与阶段适配四大检查族；
> - `webnovel-quality-check` / `webnovel-deai-lint`：独立，不做边界协调。
> **版本**：v2.0.0（破坏性改版自 v1.0.0；新增承诺链、道德情绪报偿、角色情感锚点、目标与阶段适配；评分卡六维）
> **评分口径声明**：评分口径自 v2.0 起变更（新增承诺链、角色情感锚点、目标适配；合理维度权重由 20 调整为 15），**与 v1.x 报告的分数不可直接横向比较**。如需与旧报告对比，仅可作趋势参考。
> **知识来源声明**：v2 新增检查族来自圆桌勘探报告（《梳理影响小说读者持续追读意愿的核心因素》，来源标签 free，**未外部验证**），落地后应按命中项与实际弃读章的吻合度回校。

## 一、技能定位

### 名称与触发词

- **名称**：小说追读体检器 v2（webnovel-reading-health-check-v2）
- **触发词**：小说检查、追读体检、章节诊断、逻辑自洽检查、时空错乱检查、弃书点排查、读者会不会弃书、追读健康度、承诺不兑现、挖坑不填、道德绑架、憋屈无报偿、主角没主动权、喜欢的角色消失了、发刀、套路化、看腻了、日更周更养肥、慢热劝退、卷末弃书

### 核心目标

找出影响读者「喜欢、有兴趣、能追读」的**体感、逻辑、合理、时空**问题，以及**承诺兑现、道德情绪报偿、角色情感锚点、追读目标与连载阶段错配**问题，并给出**修复优先级**。

### 适用对象

小说作者、编辑、网文写手、AI 辅助审稿、剧本/故事检查。

### 不适用

- 纯诗歌、纯学术文本、非叙事文本；
- **体外因素**：断更/改频、平台广告/推送/进度同步、读者临时状态、剧透、跨作品串名——不诊断、不展开，仅在报告附录列名备查（见"十、体外因素备查"）。

## 二、核心公式

```
完整读下去 = 喜欢 ∧ 兴趣 ∧ 能追读
```

```
追读倾向 ≈
（体感愉悦 × 逻辑信任 × 合理代入 × 时空可解 × 兴趣钩子 × 喜欢供给
  × 承诺兑现 × 道德情绪报偿 × 角色锚点存续 × 阶段目标匹配）
÷
（体感不适 × 逻辑崩坏 × 时空错乱 × 认知负荷 × 出戏风险
  × 承诺无铺垫翻转 × 情绪惯性被打断）
```

**任一项为 0，追读可能断裂。** 体检的顺序：先找"乘数为 0"的项，再算减分项。

## 三、输入格式

用户在调用时按以下结构提供，缺省字段按默认处理：

```
text
【类型】悬疑 / 言情 / 科幻 / 奇幻 / 现实 / 网文……
【目标读者】普通读者 / 老书虫 / 女性向 / 青少年 / 专业读者……
【检查范围】第 X 章 / 前 3 章 / 全书大纲 / 全文
【作者意图】想写慢热 / 想写爽文 / 想写群像 / 想写意识流……
【追更类型】日更追 / 周更追 / 养肥后补（决定单章钩子与爽点密度的诊断基准）
【连载阶段】入坑期 / 卷中 / 临近完结（决定本阶段读者目标）
【核心承诺登记】作者自陈已向读者许下的主线/CP/爽点承诺（可选；无则由体检方从正文反推）
【文本】粘贴正文
【可选】追读数据、弃书点、读者反馈
```

缺省处理纪律：

- **类型**缺失：默认按"通用网文"契约，并在报告中标注"类型契约未声明"；
- **追更类型**缺失：默认按"日更追"假设，并在报告中标注；
- **连载阶段**缺失：默认按"入坑期"假设，并在报告中标注；
- **核心承诺登记**缺失：承诺链审计所需的承诺基线**一律由体检方从正文反推**（开篇章节、卷首简介、作者的话），并在报告中标注"承诺由反推得出"；
- **检查范围**缺失：默认视为"本次提交全文"；
- **文本 > 5 章**：提示分批提交以提升精度（跨章时空/逻辑追溯依赖上下文窗口）。

## 四、检查流程：7 步（严格按顺序执行）

### 第 1 步：确认契约 + 读者画像 + 连载阶段（三确认）

本步确认三件事，缺省按第三节默认假设并在报告中标注：

**（1）类型契约**——这是什么类型？读者预期是什么？

| 类型 | 允许 | 不容忍 |
|---|---|---|
| 悬疑 | 诡计 | 线索不公平 |
| 爽文 | 巧合 | 主角降智 |
| 言情 | 慢热 | 情感逻辑不可信 |
| 科幻 | 设定复杂 | 规则不自洽 |
| 意识流 | 时空错乱 | 无美学回报 |
| 现实 | 日常琐碎 | 逻辑失真 |

> 契约缺失时，按最宽容契约假设（允许巧合但要求动机可信），并在报告中明确写出所用的契约假设。
> **报偿契约识别**：压抑-爆发长线、黑暗向、反派流等类型本就以"延迟/无传统报偿"为契约——此类契约下，"道德情绪报偿"的判定标准随契约放宽，不机械套用（见 3.9 风险 3）。

**（2）读者画像**——追更类型 + 非剧情追读目标：

- 追更类型（日更追 / 周更追 / 养肥后补）决定单章钩子与爽点密度的诊断基准：
  - **日更追** → 重点查"单章是否有独立钩子与即时回报"；
  - **周更追** → 重点查"每个更新包是否有可感知的剧情推进"；
  - **养肥后补** → 重点查"本卷是否构成可连读的完整弧"。
- 非剧情追读目标（可多选）：情绪宣泄/代偿、解谜与信息补全、角色或CP陪伴、世界观与审美体验。

**（3）连载阶段**——入坑期 / 卷中 / 临近完结：

- **入坑期**：重点查钩子与代入许可；
- **卷中**：重点查关系/世界推进与阶段性兑现；
- **临近完结**：重点查主线收束与伏笔清偿。

### 第 2 步：体感扫描

逐章标记以下 **11 组**体感坐标（记下位置与原文证据）：

| 负 | 坐标 | 正 |
|---|---|---|
| 卡顿 | 流畅 ↔ 卡顿 | 流畅 |
| 出戏 | 沉浸 ↔ 出戏 | 沉浸 |
| 憋屈 | 爽 ↔ 憋屈 | 爽 |
| 无聊 | 紧张 ↔ 无聊 | 紧张 |
| 疏离 | 共情 ↔ 疏离 | 共情 |
| 信息过载 | 信息刚好 ↔ 信息过载 | 信息刚好 |
| 疲劳 | 疲劳 ↔ 恢复 | 恢复 |
| 憋屈无报偿 | 道德情绪报偿 ↔ 憋屈无报偿 | 报偿 |
| 被动 | 主角主动 ↔ 主角被胁迫 | 主动 |
| 看穿 | 意外 ↔ 可预判 | 意外 |
| 情绪惯性打断 | 情绪延续 ↔ 惯性被打断 | 延续 |

**扫描纪律（触发式，命中相关情节才深查，不要求每章全扫）**：

- **压抑段标记**：主角持续被压制/受委屈/被迫牺牲的连续区间，检查区间内是否出现过可见反击、局部胜利或有效心理代偿（**只做有无的定性判断，不规定篇幅数字**）；
- **承接章标记**：生死决战或重大悬念揭露后的下一章，检查章首是否直接延续情绪，还是插入了功法/设定说明、前情重述（后者判为"情绪惯性被打断"）；
- **意外感标记**：本章危机/反转读者能否提前预判（可预判 = 模板化信号）。

### 第 3 步：逻辑与承诺链审计（四链）

画**四条链**，逐链追问：

- **因果链**：因为 A，所以 B，是否成立？
- **动机链**：人物为什么这么做？动机是否配得上行为？
- **规则链**：世界规则、能力规则、社会规则是否前后一致？
- **承诺链（v2 新增）**：作品已公开的承诺——类型与爽点承诺、主线目标、人设、CP 走向、关键剧情约定——后续是否被有序兑现？

**承诺链四问**：

1. **开篇承诺兑现**：开篇确立的类型定位与核心爽点，后续是否兑现？若延后，是否有人物魅力、悬念钩子等补偿在持续供给？（延后但无补偿 → 按承诺落空计）
2. **承诺翻转铺垫**：是否存在对已公开人设/CP/剧情承诺的单章翻转？翻转前正文是否有可回溯的铺垫？（无铺垫翻转 → 记为问题，不以"作者有权调整"豁免）
3. **动机转变伏笔**：主角动机的颠覆性转变，前文是否有至少一次可回溯的暗示？
4. **风格/卖点偏移**：中后期是否发生核心风格或卖点偏移（如种田日常转向朝堂权谋）？偏移是否伴随主角行为逻辑断裂、是否缺少过渡？（**判定开关是"逻辑是否断裂、有无过渡"，而非见偏移即判问题**）

### 第 4 步：合理性审计

按类型契约判断六类合理性：现实逻辑、类型逻辑、情感逻辑、动机逻辑、社会文化逻辑、专业逻辑。

### 第 5 步：时空审计

画三张表：**时间线表、空间地图、视角规则表**。

检查项：时间线矛盾、时间流速矛盾、空间跳跃、视角越界、年代错位、穿越规则混乱、多线错位、时间循环。

**锚点对照纪律（强制动作，非提示项）**：凡涉时间跨度或空间移动，须与"前文已用可验证细节锚定的跨度/距离"（如路程需三日、伤口七日愈合、季节年份）**逐项对照**，识别被无声缩短、拉长、瞬移或时间倒流。现行 v1 只查"前后时间线是否矛盾"，缺少"拿前文锚点反查无声瞬移"这个动作——v2 必须补上。

**关键纪律：先判定"错误型 vs 手法型"，再决定是否报告为问题**（判定标准见"五-D 时空错乱"）。

### 第 6 步：追读三要素审计

- **喜欢**：读者喜欢谁？喜欢什么？为什么？（v2 扩展）
  - 检查读者已投入情感的高人气配角、CP 是否仍有存续与出场（换地图/开新卷/战力膨胀后是否长期缺席或被写死）；
  - 对关键角色不可逆毁灭（发刀）章，**必须同时标注双向影响**——追求危机张力/复仇预期的读者追读上升，将情感寄托于该角色的读者可能当即弃读（禁止只标"增强追读"）；
- **兴趣**：读者好奇什么？下一章非读不可吗？（v2 扩展）
  - 检查四类非剧情追读目标（情绪宣泄/解谜补全/角色陪伴/世界观审美）在本卷是否各有供给，是否有某类提前兑现或落空后形成"下一章点击动机真空"；
  - 检查章末钩子是否需要翻多章回忆才能接上（缺锚点的复杂钩子按风险计）；
- **能追读**：文本内是否提供追读条件？（v2 扩展）
  - 检查内容供给密度是否匹配第 1 步确认的追更类型与连载阶段；
  - 主角核心目标变更后，冲突组织是否及时切换（旧目标残留组织冲突 = 阶段错配）；
  - 卷末或大高潮等"已读目标达成点"之后，是否有新悬念/新目标快速接续（否则读者点下一章动机真空）。

### 第 7 步：输出诊断与修复

按优先级五档归类所有问题，并输出完整报告（模板见"七"）：

| 档位 | 含义 | 处置 |
|---|---|---|
| 致命 | 直接弃读 | 必须修，一票否决 |
| 严重 | 大量出戏 | 优先修 |
| 明显 | 部分读者会停 | 排期修 |
| 优化 | 能读但无亮点 | 锦上添花 |
| 加分 | 强追读 | 保持并放大 |

**v2 归档优先级提示**：承诺无铺垫翻转、道德情绪长期无报偿、角色情感锚点被清零、入坑期钩子缺失，优先进入"致命/严重"档。

## 五、五维检查表

> **A/B/C/D 表沿用 v1（条目与判定标准不变）；E 表为 v2 新增。**

### A. 读者体感

| 检查项 | 苏格拉底问题 | 例子 |
|---|---|---|
| 语言流畅度 | 读起来卡吗？ | 海明威短句易读；普鲁斯特长句门槛高 |
| 节奏感 | 哪里拖？哪里赶？ | 《斗破苍穹》快；《魔戒》慢 |
| 信息负荷 | 信息过载还是刚好？ | 《沙丘》前 100 页设定密集 |
| 情绪冲击 | 爽、虐、治愈、恐惧？ | 《基督山伯爵》爽；《活着》虐 |
| 沉浸/出戏 | 哪里出戏？ | 角色降智、机械降神 |
| 共情/疏离 | 我在意谁？ | 《哈利·波特》孤儿视角 |
| 悬念/期待 | 下一章非读不可吗？ | 《达·芬奇密码》章末钩子 |
| 疲劳/恢复 | 需要喘气吗？ | 大战后插日常 |
| 画面感 | 能看见吗？ | 金庸打斗；《三体》宇宙场景 |

### B. 逻辑自洽

| 检查项 | 苏格拉底问题 | 例子 |
|---|---|---|
| 因果链 | 因为 A 所以 B，成立吗？ | 推理线索不公则弃 |
| 人物动机 | 他为什么这么做？ | 《哈姆雷特》延宕 |
| 规则一致 | 规则前后矛盾吗？ | 《哈利·波特》魔法规则 |
| 伏笔回收 | 埋的坑填了吗？ | 《解忧杂货店》闭环 |
| 推理公平 | 线索公平吗？ | 《罗杰疑案》叙述性诡计 |
| 人设稳定 | OOC 了吗？ | 角色突然降智 |
| 情感逻辑 | 态度转变可信吗？ | 《傲慢与偏见》伊丽莎白转变 |
| 世界逻辑 | 世界运行自洽吗？ | 《1984》极权逻辑 |
| 机械降神 | 突然外挂？ | 烂尾、强行巧合 |
| 承诺链 | 已公开承诺兑现了吗？（详见 E 表） | 开篇承诺迟不兑现、无铺垫翻转 |

### C. 合理

| 检查项 | 苏格拉底问题 | 例子 |
|---|---|---|
| 现实逻辑 | 现实会这样吗？ | 古装出现现代词 |
| 类型逻辑 | 类型契约允许吗？ | 爽文允许巧合，不容忍降智 |
| 情感逻辑 | 情感过渡够吗？ | 突然爱上，出戏 |
| 动机逻辑 | 动机足够吗？ | 反派为坏而坏 |
| 社会文化逻辑 | 文化上合理吗？ | 《红楼梦》诗词门槛 |
| 专业逻辑 | 专业细节对吗？ | 医疗、法律、军事错误 |

### D. 时空错乱

**先区分：错误型 vs 手法型。**

| 类型 | 检查项 | 例子 |
|---|---|---|
| 错误型 | 时间线矛盾 | 前后日期冲突 |
| 错误型 | 空间关系矛盾 | 地图前后不一 |
| 错误型 | 视角越界 | 第一人称知道别人心理 |
| 错误型 | 年代错位 | 古装出现现代词 |
| 错误型 | 穿越规则混乱 | 能力规则随意变 |
| 错误型 | 锚点无声漂移 | 前文明示"路程三日"，后文无声瞬移 |
| 手法型 | 意识流 | 《尤利西斯》 |
| 手法型 | 魔幻现实主义 | 《百年孤独》 |
| 手法型 | 多线叙事 | 《云图》《冰与火之歌》 |
| 手法型 | 叙述性诡计 | 《罗杰疑案》 |
| 手法型 | 时间循环 | 无限流、循环类网文 |

**判定标准**：

- **手法型**：可控、可理解、有意图、有锚点、有回报；
- **错误型**：失控、困惑、无提示、无回报。

无法判断时记为「疑似」，在报告中标注待作者确认，不武断定性。

### E. 承诺兑现与情绪报偿（v2 新增）

> **强制执行纪律**：本表**不要求逐章全扫 16 项**。带"位置/区间"的项（承诺翻转、承接章、发刀、压抑段、兑现节点时序、动机接续）**仅在文本出现对应触发情节时才检查**；每章例行必查的仅 4 项：开篇承诺兑现、道德情绪报偿、角色锚点存续、意外感。其余项按触发式执行。

| 检查项 | 苏格拉底问题 | 执行方式 |
|---|---|---|
| 开篇承诺兑现 | 开篇承诺的类型与爽点，后文给了吗？没给的话有补偿吗？ | 例行必查 |
| 承诺翻转铺垫 | 人设/CP/剧情被推翻前，正文埋过可回看的线索吗？ | 触发式（出现翻转时） |
| 动机转变伏笔 | 主角动机突变，前文有暗示吗？ | 触发式 |
| 风格卖点偏移 | 中途换风格/卖点，有过渡吗？主角行为逻辑断了吗？ | 触发式 |
| 兑现节点时序 | 开章的疑问拖了太久吗？高潮和成长挤在同一章互相抵消吗？ | 触发式 |
| 道德情绪报偿 | 主角被胁迫/受委屈/牺牲后，叙事给了报偿吗？ | 例行必查 |
| 主角主动权 | 是谁在推动事情？主角是在主动选择还是被外力推着走？ | 触发式（压抑段） |
| 压抑段代偿 | 被压制的段落里，有反击、小胜或心理代偿吗？ | 触发式（压抑段） |
| 角色锚点存续 | 读者喜欢的配角/CP 还在吗？换地图后多久没出现了？ | 例行必查 |
| 发刀读者分化 | 这个角色之死，会让哪类读者更想读、哪类读者立刻走？ | 触发式（发刀章） |
| 非剧情目标供给 | 本卷照顾到宣泄/解谜/陪伴/审美四类读者了吗？ | 触发式（卷末盘点） |
| 阶段目标匹配 | 当前连载阶段，读者要的和内容给的是同一件事吗？ | 触发式（阶段确认后） |

| 承接章惯性 | 高潮后的下一章，开头是在续情绪还是在灌设定？ | 触发式（承接章） |
| 意外感 | 这次危机/反转，读者能提前猜到吗？ | 例行必查 |

## 十一、已知局限性

1. **跨章长程检测受限**：单次 1-5 章内可准确识别局部时空/逻辑矛盾；跨 10 章以上的长程伏笔回收、人物弧光追踪依赖上下文窗口，超范围部分仅在报告中提示"需回查 X 章"，不做武断结论。
2. **类型契约假设风险**：作者未声明类型时，本 skill 使用默认契约假设；若实际类型不同，部分结论可能偏移，报告中会明确标注所用假设。
3. **专业逻辑判定**：医疗/法律/军事等专业错误依赖训练知识，可能漏判或误判，凡不确定者仅标"疑似专业存疑"。
4. **主观维度边界**：体感、情绪冲击等维度的评分带有主观性，报告中与客观逻辑问题分开呈现。
5. **承诺/情绪类结论未外部验证**：承诺翻转、道德情绪报偿、角色锚点等检查族来自圆桌勘探的经验归纳（来源标签 free），其触发弃读的临界条件未经真实读者数据验证，落地后应按命中项与实际弃读章的吻合度回校。
6. **读者群分化判定的主观性**：发刀等情节对不同读者的相反影响，依赖对读者构成的判断，报告中以"双向假设"呈现而非单一结论。
7. **体外因素不在诊断范围**：断更、平台广告/推送/进度同步、读者临时状态、剧透、跨书串名等可独立导致弃读，本体检不覆盖（见"十、体外因素备查"）。

## 十二、执行纪律（Do / Don't）

**Do**：
- 严格按 7 步顺序执行；先找"乘数为 0"的致命项，再做减分项排序；
- 每个问题必须带位置 + 原文证据（≤30 字）+ 影响 + 修复处方；
- 时空错乱先判"错误型 vs 手法型"再定性；时空锚点对照为强制动作（拿前文锚点反查无声瞬移）；
- 承诺链必查：翻转/偏移/动机转变先问"有无铺垫与过渡"，再下定性；
- 发刀等强情节必须给"读者群分化"双向判断，禁止只标"增强追读"；
- E 表按表头纪律执行：例行必查仅 4 项，其余触发式，不逐章全扫 16 项；
- 所有新增检查族的判断一律**定性**，不设定具体篇幅/数量数字阈值；
- 评分必须与问题清单互相印证（有致命项不得给高分档）；
- 类型契约/追更类型/连载阶段/承诺基线未声明时，先声明假设再体检，报告头部列"诊断假设"区。

**Don't**：
- 不改写原文（除非用户明确要求"帮我改"）；
- 不武断定性无法判断的时空/专业/分化问题（标"疑似"或"双向假设"待作者确认）；
