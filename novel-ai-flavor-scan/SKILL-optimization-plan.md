## 模块 1 · 真实诉求重述 & 成功标准

**真实诉求**：不是"把 report.md 搬进 SKILL.md"，而是——在**完全保留 8 元盘问引擎 × 16 维扫描 × 判断顺序铁律这套骨架**的前提下，给现有探测器**补上它抓不住的盲区特征**（物理破绽、对话机械模式、专名异常、视角漂移、跨章事实矛盾），并把这些新特征**从"模糊的定性描述"变成"可量化、可执行、可对账的触发规则"**，同时用反例刹车闸防止新特征引入误判。

一句话：**骨架不动，换上更锐的眼睛和更硬的标尺，且每个判断都可追溯到出处。**

**成功标准（可验证）**：

1. 方案中每条优化都映射到 SKILL.md 的具体章节，且不动 8 引擎 / 16→18 维结构 / 五档分级；
2. 每条新特征都有 **触发条件 + 原文证据要求 + 误判排除** 三件套，规则可量化执行；
3. 附完整处置台账，`report.md` 的内容逐条有归宿，0 遗漏；
4. 所有量化数字要么来自 `report.md` 且标行号，要么显式标为 `[AI 推断·需验证·占位]`——**无一处编造的伪精确**。

## 模块 2 · 推荐方案 & 设计权衡（终稿规则）

**方案主线：「增量挂载式优化」——三层动作，一次完成。**

### 动作一：特征增量（提升召回，主攻）

给现有维度**挂载** report.md 挖出的新观测点，并升格两个强信号为独立维度：

| 新特征 | 挂载位置 | 依据 |
|---|---|---|
| 物理守恒破绽（物品消失/视线矛盾/动作倒序） | D8 场景维 · 二级观测点 | B027、结论 7 |
| 5 种对话机械模式 | D4 声音维 · 二级观测点 | B013、结论 5 |
| 视角漂移 / 第三人称越界获知 / 模板化时空过渡 / 空间清单式罗列 | D3 叙事维 · 二级观测点 | B014、结论 6 |
| 标点组合密度异常（省略号↔破折号短距交替） | D1 语言维 · 二级观测点 | B018、结论 7 |
| 内嵌第三方内容适配度 | D15 互文/平台维（辅助参考，不得单独定性） | B019、结论 8 |
| **跨章事实一致性** | **新 D17（独立维度）** | B005、结论 14 |
| **虚构专名语义透明度 + 跨章稳定性** | **新 D18（独立维度）** | B022、结论 4 |

**为何升格只有两条**：D17 是全文级事实网络（人物身份/时间线/空间/物品归属/伏笔承诺），D18 横跨语言层与元系统层——放任何现有维都语义委屈；其余特征都能干净归入现有维，不升格。

**权衡**：16→18 维使扫描成本 +12.5%，换取对"长篇 AI 小说"最典型两类破绽的捕获能力；成本靠"挂载不加引擎轮"压回。

**新特征的二级观测点明细**：

- **D8 物理守恒破绽（B027）**：① 手中物品在场景转换后凭空消失或换手；② 视线朝向与对话对象位置矛盾；③ 肢体动作顺序违反时间先后（如先倒茶后拿杯）。
- **D4 对话机械 5 模式（B013）**：① 问答完全对称无偏差；② 无日常寒暄直接切入核心信息；③ 对同一信息无意义重复确认；④ 对话仅服务信息传递、无冗余闲聊；⑤ 角色语气无个人化起伏、完全贴合功能需求。
- **D3 叙事异常（B014）**：① 聚焦者在段落间无提示漂移；② 第三人称有限视角越界获知未在场人物心理；③ 场景/时间跳转依赖"与此同时""几天后"等模板化过渡；④ 空间描写呈清单式罗列，而非随人物视线移动渐进呈现。
- **D1 标点密度（B018）**：省略号与破折号在短距离内（同段/相邻对话行）高频交替；破折号频繁用于模拟话语中断。
- **D15 内嵌内容（B019）**：新闻、法条、歌词等第三方内容未做叙事语境改写/注释，与上下文适配度显著偏低——**辅助参考，禁单独定性**。

### 动作二：量化标尺（提升可执行性，终稿规则）

把 report.md 的定性结论转译为**连续谱内部的触发锚点**，不引入积分制。

**R1 · 单条信号封顶规则（T1 终稿）**

- 单条二级观测点单独命中 → 维度分**最高可给至 60**，但**等级结论封顶"中度（41–60）"**，报告强制标注 `⚠️ 单一线索，待共现确证`；
- 进入 **61+ 档（高/极高、触发"系统性重写"建议）的唯一路径**：≥2 维共现，或本维内 ≥2 个观测点命中；
- 落点：SKILL.md §6.2（输入端约束）+ §9.4（红队标注项）。

**R2 · 15% 阈值的正确语义（T2 终稿）**

- 冗余修饰句占比 >15% → **证据强制入链**（正奇引擎不可跳过）+ 维度分**不低于 41 的托底**；
- 61+ 仍须 8 引擎交叉修正 + 红队排除后才可进；
- 红队排除成功（如 B025 功能性重复）→ 托底**撤销**，分数回归引擎修正；
- 落点：SKILL.md §6.2 触发锚点表。

**R3 · 误判风险等级标注**

- report.md 的等级口径（高 ≥30% / 中 10–30% / 低 <10%）→ 转为 §6.1 新增的"人类误写风险"标注列；
- **低风险项才允许计入高分档**；每条 AI 正信号配套人类误写例子。

**R4 · 最小文本单元 + 聚合规则**

- 按 B023 明确每条特征适用的最小单元（单句/段落/场景/章节/跨章节）；
- 转为[专项 B 输入分级规则](#专项-b)。

**权衡说明**：report.md 的 ≥3/≥6 积分硬闸门被放弃（与 0-100 连续谱是两套哲学）；其**精神**（共现加权、阈值触发）通过 R1/R2 输入端约束完整保留，公式本身（加权几何平均）不动。

### 动作三：边界与降级（防误判与过度断言）

1. **三层人类基线**合并为新章节 §6.4（详见[专项 A](#专项-a)）；
2. **输入分级 + 显式降级**（详见[专项 B](#专项-b)）；
3. **前提假设显式化**：B003/B008/B011/B017/B021/B026 升格进 §2.3 与 §12；
4. **人工润色退出信号（T4 终稿）**：识别到人工润色/多轮改写痕迹 → 显式声明"超出本 Skill 分析边界（依据 B008）"，**停止评分、不给 0-100 分**。

### D17 / D18 执行方式适配（T5a 终稿）

- D17/D18 保持独立维度，但其证据采集走 **"预处理层全文索引一次 + 8 引擎只对异常点盘问与红队"**：
  - 预处理层统一构建**事实网络索引**（人物身份/能力/时间线/空间/物品归属/伏笔承诺）与**专名索引**（人名/地名/店名及其跨章复用）；
  - 8 引擎不对全书逐段盘问，只对索引暴露的**异常点**执行盘问、钢人与修正；
- **不改架构**（引擎数、维度、判断顺序不变），只给新维度指明证据从何而来，避免"7 个引擎空转"。

<a id="专项-b"></a>
## 专项 B · 输入分级与显式降级规则（落点 SKILL.md §7 + §8.4）

| 输入规模 | 可检测特征 | 处理方式 |
|---|---|---|
| 单段 / 单场景 | 语言、节奏、声音（对话机械）、标点密度、物理守恒破绽 | 正常评分 |
| 多段 / 单章 | 以上 + 视角漂移、情感、人物、场景、内嵌内容适配 | 正常评分 |
| ≥2 章 / 全文 | 以上 + **D17 跨章事实一致性、D18 专名稳定性** | 全文级特征启用 |
| 任意规模 | 未启用维度 | **显式列"本项未检测（样本不足）"**，不计入总分，下调置信度 |

**配套硬规则**：

1. **总分只基于"实际检测的维度"重算几何平均**——未检测维度不得按 0 分（错误拉低）或默认分（虚高）混入；
2. **置信度随检测覆盖率下调**，报告抬头标明 **"片段扫描 / 全文扫描"**；
3. **未检测维度合并为一张表**（不逐维散落），控制报告膨胀；
4. **严禁静默降级**。

### 反向边界声明（NOT 适用的 3 种场景）

1. **人工深度润色稿** → AI 残留被稀释、分数虚低 → 触发 T4 退出，声明边界；
2. **非叙事文本**（论文/新闻/说明书/诗歌）→ 18 维全是小说叙事假设、无对象可检 → SKILL 已声明不适用；
3. **单段摘抄 + 要求作者身份级判定** → 片段证据不足却被当身份判决 → 抬头"片段扫描" + §12 不判作者；坚持要身份结论则拒绝输出。

### 逆向验收结论

- 核心目标"更准确找出 AI 味"：✅ 召回（7 项新特征）+ 精确（§9.3 + 三层基线）双侧覆盖；
- C01–C13：逐条核对 ✅ 全部满足；
- 唯一不可内解风险：**A2 D17/D18 窗口极限** → 由模块 6 击穿实验回答。

### 终稿修正条款（T1–T5，已锁定）

- **T1**：单条信号最高 60、封顶中度、进 61+ 需 ≥2 点共现；
- **T2**：15% = 证据入链 + ≥41 托底，红队排除可撤销；
- **T3**：L2 占位值 + 强标注，仅排除参考、不进公式；
- **T4**：混合文本一律退出、不给分（B015/结论 12/步骤 7 维持不采纳）；
- **T5**：a) D17/D18 预处理索引 + 异常点盘问；b) 篇幅二分；c) 台账 53 项。
