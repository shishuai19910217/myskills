```
T0.1 → T0.2 → T0.3 → T0.4
                    ↓
                  T1.1 → T1.2 → T1.3 ─┬→ T1.4
                                      └→ T1.5 → T1.6
                                              ↓
                                    T2.2 → T2.3 → T3.5 → T3.6
                                              ↓          ↓
                                    T2.1 → T2.4 → T2.5  T3.7 → T3.8 → T3.9
                                              ↓          ↓          ↓
                                            T2.6      T3.1→T3.2→T3.3→T3.4
                                                            ↓
                                                       T4.1 → T4.2 → T4.3 → T4.4 → T4.5
```

**最长链**：T0.x → T1.x → T2.2 → T2.3 → T3.5/6 → T3.7/8/9 → T4.x
**无缓冲环节**：T2.3 与 T3.6 之间只有 T3.4/T3.5 可并行，T4 阶段无任何前置缓冲。
**最易滑期**：T2.4（对照实验最容易超时）→ 预留了裁剪路径。
