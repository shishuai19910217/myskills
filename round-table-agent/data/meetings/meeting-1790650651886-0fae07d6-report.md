### 步骤一：建立文本坐标系（做什么 / 怎么做 / 验收标准）

1. **做什么**：为全书正文建立“章号—段落—功能”基础坐标表，作为所有诊断的落点。
2. **怎么做**：逐章列出章号、场景起止段、章末最后 5 段原文摘录、章内新出现的设定/角色/伏笔条目。摘录原文以满足**可指认文本位置**的前提要求。
3. **验收标准**：任意一条诊断都能反查到具体章号与段落；无法定位的问题一律标“待核查”，不进入正式清单（依据 B004、B007）。

### 步骤二：章末断点审计（读者体感主线）

1. **做什么**：逐章判定章末属于哪类断点，识别“日常收尾无期待点”的削弱段落。
2. **怎么做**：将每章末段归入四类——①未闭合冲突/悬念断点；②场景切换收尾；③旁白总结收尾；④日常收尾+末段暗线钩子。对④类逐个抄录末段原句，核验其是否**真实产生翻页冲动**且**非孤例**；对无钩子的④类与②③类逐条登记为症结。
3. **验收标准**：全书每章末均有四类之一的归类标签；②③④无钩子类的症结条目附“建议改为停在何处”的具体修改方案（依据 B002、B003、B005）。

### 步骤三：开篇钩子与阶段目标审计（读者体感 + 承诺兑现）

1. **做什么**：诊断前三章钩子与全书阶段性期待目标的缺失情况。
2. **怎么做**：
   - 前三章逐段标注：该段承担的钩子是什么、针对哪种弃读风险（无期待感、无目标、无冲突等）；
   - 检查正文是否以任务清单、境界数值、对手对位等方式**标出可递进、跨章累积的目标**；缺失处列为症结并给出“在何章插入何种标示”的修改建议；
   - 建立开篇目标追踪表：三秒胜负条件/对手/悬赏的**首次交代段落 → 后续每次复述的章号**，标注断链点与中途搁置的目标。
3. **验收标准**：每个开篇目标在追踪表中有“设立章”和“最后一次提及章”；断链目标逐条给出“续接或删除”的二选一建议（依据 B001、B006、B011、B016）。

### 步骤四：“三秒无敌”规则一致性审计（逻辑自洽 + 合理性）

1. **做什么**：核验能力规则的完整性、交代时机与成文约束资格。
2. **怎么做**：
   - 收集全书所有涉及**持续时间、计量单位、触发条件、冷却、次数上限**的规则句，逐项标注“已写明/仅书名暗示/未发现”；
   - 核对规则是否在**首次实战出手并揭晓胜负的同一章内**完整交代，延后者列为症结；
   - 单独审查是否存在把剧情设定**误当作创作约束**（如据“三秒”推断章内只能有一个场景）的判断，凡无正文原句支撑者不予采纳；
   - 排查决胜关口是否有成段规则解说/回忆中止胜负交代。
3. **验收标准**：四项规则（时长、单位、触发、冷却/上限）各有明确判定；每条“延后交代”症结附“移入首战章”的改写位置建议（依据 B007、B008、B014、B017）。

### 步骤五：时空错乱与信息密度审计（时空错乱 + 合理性）

1. **做什么**：定位时序混乱、场景衔接断裂与信息过载段落。
2. **怎么做**：按步骤一坐标表核对相邻章节的时间标记与场景衔接；统计**单场景抛出三条以上新设定/新角色/新伏笔且章内未回收**的段落，记录频次与章位；定位**本章过半前冲突已闭合、后半仅剩过渡旁白**的章节及起始段落。
3. **验收标准**：每处时序断层或信息过载给出“删除/合并/后移/提前呼应”之一的处置建议；无问题的子项明确写“未发现”（依据 B010、B020、B004）。

### 步骤六：情绪报偿与重复结构审计（承诺兑现与情绪报偿）

1. **做什么**：诊断报偿过早闭合、知情差空耗与同类冲突无递进三类问题。
2. **怎么做**：
   - 复核第12章原文，确认战利品清点、路人跪谢、“等你伤好再联手”预告是否**在同一章连续堆叠**；属实则给出“保留至章末断点、其余后移”的拆分方案；
   - 全书检索“只有他知道”“无人察觉”“她没有告诉任何人”类限定语句，逐条判断其是否**错开读者与主角的知情**、空耗追读期待，属实者建议改为章内揭示或降级为可回收暗线；
   - 对相邻章节同类胜负流程（三秒反杀、嘲讽打脸）做对照表，比对敌人层级、规则代价、主角处境、视角信息差四个字段是否存在可验证升级，无递进者标注对下章期待的衰减影响，并明确区分“未发现”与实际重复段落。
3. **验收标准**：第12章有明确“属实/不属实”结论及处置；知情差语句清单逐条给出删除或改写建议；重复结构对照表四字段均有“升级/持平/未发现”标签（依据 B012、B015、B018、B013）。

### 步骤七：汇总产出诊断清单

1. **做什么**：将六步结果合并为最终交付物。
2. **怎么做**：按五维度分组输出表格，每条含【症结描述 / 章号段落定位 / 对“读下去”的影响机制 / 可执行修改建议 / 依据边界 ID / 可信度】；末尾附“未发现项”专区，集中列出经核查确无问题的子维度。
3. **验收标准**：五个维度及总目标“读下去”均有条目或明确“未发现”；每条建议可直接指导改稿且有验收方式；全部边界 ID 至少被引用一次。

## 风险与前提

- **文本可定位性前提**：若“章末断点、爽点、伏笔”无法落到具体段落，则整份诊断退化为印象式评价，方案失效（依据 B004）。
- **概念层级前提**：若把剧情金手指规则直接当成创作约束（如由“三秒”推断场景/视角限制），步骤四的规则审计会产出伪症结，方案失效（依据 B007、B014、B017）。
- **开篇钩子前提**：前三章若未逐一标明钩子对应的弃读风险，读者体感维度的诊断缺少抓手，留存归因不可靠（依据 B001、B011）。
- **章末断点前提**：若默认“必须停在冲突上”而忽略“日常收尾+暗线钩子”的真实有效性，会误杀有效断点；B003 反例需先核实再下结论（依据 B002、B003、B005）。
- **低可信度条目风险**：B006（阶段目标缺失）、B013（拖沓后兑现）初始可信度为 low，未逐章确认前写入结论会导致误诊（依据 B006、B013）。
- **第12章个案风险**：B018 基于单一章号的观察，若原文不符，情绪报偿维度的“过早闭合”症结需重新举证（依据 B018）。
- **重复结构误判风险**：若不区分“未发现”与“实际重复”，B015 会把结构变奏误标为无递进，产生虚假症结（依据 B015）。
- **信息密度阈值风险**：“三条以上新设定”的计数口径若不统一，B010 的统计结果不可复现（依据 B010）。
- **中段断点风险**：B020 仅覆盖“过半前闭合”的章节，后半章无钩子的情形需另行扩展，否则诊断遗漏（依据 B020）。
- **知情差判定风险**：B012 若按字面禁用一切限定语句，会误伤合法的信息差悬念；须以其是否“空耗追读期待”为判准（依据 B012）。
- **范围边界前提**：凡超出正文本身的问题（文风美学、题材前景、发行策略、非正文文件）不在诊断范围，纳入即视为超范围失效。
