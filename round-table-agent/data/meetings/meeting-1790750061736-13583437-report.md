### 六、全局共性问题（六条）

1. **系统规则未成文**——全篇唯一解释链"被人相信才强"没有任何一处可核账本：读数是存量还是单次增量、是否逐人递增、跨日是否清零、相邻读数间的涨跌来源、出手是否消耗、「信仰若断，战力归零」是否与"战力：0"联动，全部悬空（B002、B003、B005、B012、B020、B034）。这是唯一的 P0 级共性问题。
2. **面板可见性从未择一**——B007、B037、B040 三条从不同段落逼近同一空白：若面板仅宿主可见，秦烈的每一次动摇与旁人的每一次散去都缺公开依据；若他人可见，则每场显圣都自带拆穿证据。
3. **主角自我陈述反复自相矛盾**——第1节断言被当场推翻（B001）、三场显圣目标函数中途换轨（B009）、第3段"代价不可被看见"与结尾万人围观的画面互斥（B050、B051）、第4段"力量全靠人信"与"跟信不信没关系"互斥（B055、B057、B067）。四段各犯一次，形态不同，病根同一：结论句先写、机制后补。
4. **视角与信息来源越权**——背身／闭眼时描写对方神色与手部（B015）、位置锚点四处冲突而结算仍弹出（B028）、哑巴亲手写字（B015）、以"我"目击却读不出内容（B059）、同门私下议论被逐字还原（B063）、私密结果不经作证即成人前事实（B022）。
5. **规则支撑只在关键处缺席**——真元剑当众见血无约束（B043）、硬接一剑靠万人失声（B044）、镜阵火油烟花无权限链（B038）、戴罪阿砾入场无准行（B048）、宗门四项处分授权无条款出处（B036）、清场独斗时秦烈不敢递剑缺成文约束（B027）。
6. **情感支点单薄且无前置兑现**——阿砾在第2段零铺垫引入（B023）、在第3段仅为旁观者而非动机来源（B042）、在第4段以"演"的双读悬置（B062、B066）；碎碑挡赵横这条全篇唯一旧事锚点仅有群体转述（B054）；身体反应词四处同源复用（B018）。

## 关键分歧与裁决

本轮无条目被否决或合并（保留 72 / 合并 0 / 否决 0），但存在 8 组表面冲突。裁决原则：**先判定两条是否落在同一覆盖面，再决定是并存还是解除**。凡被判为"防误诊锚点"的条目一律保留在边界池内、仅取消其作为缺陷的定性资格。

1. **B006 vs B016**：B016 主张「回头看了三次人数」若对应数"三、二、一"的三声停顿（12→19 连跳），则属可辩护留白；B006 攻击的是第4节影子／回声这一处。两者覆盖面不同，**并存**。裁决：B016 仅解除第3节"数人"处的指认悬空，B006 仍成立且优先级维持 P0。
2. **B021 vs B032**：B021 证明第2段以"第五天""第三天，演武场""大典前夜"等锚点串起近十次切换且各带独立画面，时空本身清晰；B032 攻击的是起算锚点不统一与倒挂可能。**并存**。裁决：不得下"全段时空混乱"的诊断，但"起算锚点"须单列并列入 P2。
3. **B026 vs B020**：B026 证明结算与归零两处均明写"板子"、可归宿主视野，412/380/301 可逐场对号；B020 指出独斗裸行 1/2/1 缺归属与增减来源。**部分解除**。裁决：B020 收窄为"只攻击第一处数字"，P0 保留但范围限定在 1/2/1 与 8%/1人换算。
4. **B035 vs B019／B033**：B035 证明主角主动泡演武场记出招习惯、旧伤与破绽，后续心理博弈靠此发起；B019、B033 指出的是目标取向相反与取舍被跳过。**并存**。裁决："全段被动"这一诊断被击穿，但 B019、B033 在"取舍判据缺失"层面仍成立，留在 P2。
5. **B039 vs B047／B044**：B039 指出零代价替代路径（私下试剑、延后请柬、当场收回）在段内零否决。B044（劈剑前无在场干预）与 B047（赌约判定悬空）实际已从"路径唯一性"侧翼包抄同一动机缝。**并存且合并关注**。裁决：三者合观指向"代价是被默认接受而非剧情唯一解"，统一在 P1 处理，不重复计入。
6. **B049 vs B051**：B049 主张收尾已用最极端坦白清空风险，故"缺备用路径"不成立；B051 指出代价"不可被看见"在可验证画面上完全未兑现。**并存**。裁决：B049 限定其防守范围为"叙事缺口"维度并降为锚点＋动机缝，B051 指向"画面兑现"维度，独立保留 P1。
7. **B055／B067 vs B062／B066**：B055、B067 攻击的是"力量全靠人信"与"跟信不信没关系"的互斥；B062、B066 证明"演"字双读与同门称谓未注销两种读法同等成立。**并存**。裁决：前者属"结论句互斥"（P0），后者属"表述可两解"（P0 内单列），不得用"多义"来稀释互斥的定性。
8. **B043 vs B044**：B043 要求真元剑留手须有宗规或现场约束，并禁止其与结尾认输的和解矛盾；B044 指出"硬接一剑"依赖万人集体失声而非规则唯一。**并存互补**。裁决：一为"约束缺失"，一为"路径非唯一"，同列 P1，须在同一次修订中一并落地。
