## 四、最终解决方案

## 方案概述
本方案输出一套可服务于人工初筛与复核的AI生成小说“AI味”特征判定清单，覆盖词句、修辞、对话、叙事、人物等9个可观察层级，明确排除人类固有文体惯例与模板化写作的干扰项，支持多条特征共现加权判定，默认针对未做垂直优化的通用大语言模型直出小说文本，可有效区分AI独有特征与人类写作共性特征。

## 关键结论
1. 连续三段式排比、章回体回末程式化总结陈词、侦探小说结尾复盘独白、网文/青春文学高频使用的显性逻辑衔接词、情绪直给点题、模板化场景切换、人类作家固定意象群复用、服务于叙事功能的语义偏移性重复（如意识流心理复现、侦探线索刻意重复、史诗母题递进性复沓）均属于人类写作的固有惯例或共性特征，不能单独作为AI味判据（依据 B2、B7、B12、B16、B20、B25）
2. 在常规生成参数下，不随文本长度、题材、语言改变而消失的稳定AI味特征包括：高频重复关联词套用、无实际语义增量的冗余修饰句占比超15%、人物动机完全服务于情节推进的套路化塑造、多轮续写拼接处的人物/设定自相矛盾与突兀遗忘、篇章结尾强制概括主题的总结性陈词、情节转折处依赖“然而/就在这时”等模板化过渡句（依据 B6、B8）
3. 需优先建立人类模板化写手基线以排除误判：四字成语/排比密度、总分总段落结构、每章末尾钩子句式、形容词堆叠等特征在日更网文作者、公式化畅销书作者的人类文本中同样高频出现，需先对照基线区分“AI独有特征”与“人类模板化写作共性特征”（依据 B4）
4. 长篇与短文本的AI味特征存在差异：长篇中人物外貌/口头禅逐字高频重复、虚构专名稳定性失守（同名配角跨章重现、角色名异写/别名漂移、音近字近角色混淆）是长篇可辨识的AI味特征，需注意区分人类长篇连载为照顾读者而作的信息复述惯例，避免误判（依据 B9、B22）
5. 对话场景的机械性互动模式是强AI味特征：问答完全对称无偏差、无日常寒暄直接切入核心信息、对同一信息无意义重复确认、对话仅服务于信息传递无冗余闲聊、角色语气无个人化起伏完全贴合功能需求，是人类写手极少采用的模式（依据 B13）
6. 叙事视角与时空呈现的异常是核心判定维度：段落间聚焦者无提示漂移、第三人称有限视角越界获知未在场人物心理、场景/时间跳转依赖“与此同时”“几天后”等模板化过渡、空间描写呈清单式罗列而非随人物视线渐进呈现（依据 B14）
7. 标点与物理细节的异常可作为辅助判定依据：短距离内省略号与破折号高频交替、破折号频繁模拟话语中断，以及角色连续微动作中的物理守恒破绽（手中物品凭空消失/换手、视线朝向与对话对象位置矛盾、肢体动作顺序违反时间先后）（依据 B18、B27）
8. 内嵌第三方内容的适配度可作为辅助参考：小说内嵌的新闻、法条、歌词等内容未做叙事语境改写/注释，且与上下文适配度显著低于人类同类创作平均水平时可作为辅助依据，不得单独判定（依据 B19）
9. 特殊文体的AI味判定需调整参照系：翻译腔作品豁免欧化句法、高频逻辑连接词的判定；方言/仿古作品将判定重点调整为“方言语法被强制清洗为普通话”“仿古叙事出现现代抽象心理名词的时代穿帮”（依据 B21）
10. 第一人称/现在时/书信日记体仅豁免表层叙述特征豁免：如“我感到/我意识到”等即时自述、现在时短句、情绪直接命名、日期称呼等符合人物认知与文书逻辑的不算AI味，但人物标签化、动机单一、配角工具化等跨场景模式仍可判定（依据 B24）
11. 判定需遵循共现加权与单元级规则：单条特征仅作为可疑线索不能单独定性，需明确每条特征适用的最小文本单元（单句/段落/场景/章节），以单元级特征出现频次、叠加程度及跨单元一致性作为聚合判定规则，且需标注每条特征的人类误判风险等级；所有特征判定均需满足“单篇盲读可独立识别”的要求，若某特征必须通过人机对照或统计比较才能显现，则不属于可独立辨识的AI味特征（依据 B10、B17、B23）
12. 多轮交互式分段续写的AI小说，需先区分单轮生成固有模式残留与人类修改引入的个性化特征，仅前者可作为AI味判定依据（依据 B15）
13. 采样参数在常规区间内变动时AI味特征不会本质改变，仅当采样温度、随机种子、模型版本调整幅度超出常规生成阈值时才会出现可观察波动（依据 B11）
14. 跨段落与跨章节的事实一致性是核心校验维度：人物身份、能力设定、时间线、空间位置、物品归属、伏笔承诺与已述事件的无提示矛盾或重复可作为强判定依据（依据 B5）
15. 当前清单默认各类读者对AI味特征的敏感度与误判率相同，若实际判定场景中读者画像差异显著（如只读网文者忽略句法特征、只读纯文学者误判网文惯用句式、非母语者将合法搭配误判为机械表达），需按读者分层标注误判方向（依据 B26）

## 落地方案
### 模块1：特征清单分层构建
#### 步骤1：按可观察层级拆分特征维度
- 做什么：将AI味特征拆分为9个可观察层级，覆盖词句层（含标点、关联词、用词）、修辞描写层、对话层、段落推进层、情节结构层、人物塑造层、情感表达层、结构节奏层、整体印象层
- 怎么做：每个层级下列举具体特征条目，每条条目明确4个必要要素，对应规则如下表：
| 要素类别 | 说明 |
| --- | --- |
| 具体文本表现 | 该特征在AI生成文本中的典型文本样例 |
| 人类误写例子 | 人类作者同类写法的合法样例 |
| 人类误判风险等级 | 高（人类同类写法占比≥30%）、中（10%≤占比<30%）、低（占比<10%） |
| 适用最小文本单元 | 单句/段落/场景/章节 |
- 验收标准：覆盖边界B001要求的全部层面，每条特征包含4个必要要素，无遗漏核心维度
#### 步骤2：排除人类固有惯例干扰项
- 做什么：将边界明确的人类文体惯例特征标注为“不可单独作为判定依据”，仅作为共现加权时的辅助线索
- 怎么做：在每条对应特征后标注“⚠️ 人类惯例干扰，不可单独定性”，并附人类文本中的对应例子
- 验收标准：所有人类固有惯例特征均完成标注，无遗漏
#### 步骤3：建立人类写手基线对照规则
- 做什么：针对B4要求的高频误判特征，建立人类模板化写手基线对照流程
- 怎么做：采集日更网文作者、公式化畅销书作者的同类题材文本作为对照基线，统计四字成语密度、排比密度、总分总段落占比、章末钩子句式占比、形容词堆叠占比等指标，若AI生成文本的指标处于人类基线区间内，则排除该特征作为AI味判定依据
- 验收标准：完成至少2类人类写手的基线数据采集，明确各指标的基线区间
#### 步骤4：明确特殊场景豁免规则
- 做什么：针对B21、B24要求的特殊文体与叙述视角，制定豁免与调整规则
- 怎么做：翻译腔作品豁免欧化句法、高频逻辑连接词的判定；方言/仿古作品将判定重点调整为“方言语法被强制清洗为普通话”“仿古叙事出现现代抽象心理名词的时代穿帮”；第一人称/现在时/书信日记体豁免表层自述式表达、情绪直给、日期称呼等符合人物认知的特征
- 验收标准：特殊场景的判定规则无冲突，覆盖所有边界要求的豁免场景
### 模块2：共现加权判定流程
#### 步骤5：制定单元级特征校验规则
- 做什么：按照B23要求，明确每条特征的适用最小文本单元，制定跨单元聚合判定规则
- 怎么做：单句级特征（如关联词套用、形容词堆叠）需统计单章节内出现频次，若占比超阈值则标记为可疑；段落级特征（如总分总结构、视角漂移）需统计连续3个段落内出现次数；场景/章节级特征（如情节套路化、人物标签化、伏笔机械回收）需统计2个以上场景/章节的重复出现次数；跨章节级特征（如事实一致性、专名稳定性）需覆盖全文校验
- 验收标准：每条特征均标注适用单元，聚合规则可量化执行
#### 步骤6：建立加权判定矩阵
- 做什么：按照B10要求，制定共现加权规则，明确单条特征不可定性，多条特征共现时按风险等级加权
- 怎么做：高风险特征（跨章节事实矛盾、视角越界、对话机械互动、物理守恒破绽）权重3，中风险特征（叙事视角漂移、空间描写清单化、内嵌内容适配度低、标点异常）权重2，低风险特征（单句关联词套用、形容词堆叠、单场景情绪直给）权重1；单条特征得分≥3分为可疑，≥6分可判定为AI味；同一特征在多个单元重复出现额外加1分
- 验收标准：加权规则可量化，无主观判断空间
#### 步骤7：多轮续写文本的区分规则
- 做什么：针对B15要求的多轮交互式续写文本，制定模式区分规则
- 怎么做：先识别单轮生成的固有模式残留（如关联词套用、冗余修饰句、拼接处矛盾），再识别人类修改引入的个性化特征（如人物个性化对话、非模板化情节），仅前者计入AI味判定
- 验收标准：可明确区分两类特征，避免将人类修改内容误判为AI味
### 模块3：校验与迭代
#### 步骤8：盲测校验
- 做什么：组织测试者对标注好人类/AI来源的文本进行盲测，校验清单的准确率与误判率
- 怎么做：选取100篇未做垂直优化的通用大模型直出小说，100篇人类模板化写手小说，50篇人类纯文学小说，让测试者按清单规则判定，统计准确率、误判率、漏判率
- 验收标准：整体准确率≥85%，人类模板化写手文本的误判率≤10%
#### 步骤9：迭代优化
- 做什么：根据盲测结果调整特征权重与判定规则
- 怎么做：对误判率高的特征调整权重或补充人类误写例子，对漏判的特征补充到清单中
- 验收标准：迭代后准确率提升≥5%，误判率≤8%

## 风险与前提
1. 前提B3不成立（所分析文本为垂直微调或定向提示词约束生成的AI小说）：方案中针对通用大模型直出文本的特征判定规则将失效，需补充垂直优化模型的专属特征库
2. 前提B8不成立（被分析文本经过人类重构与润色）：单轮生成的固有模式残留可能被人为修改，机械拼接处的矛盾、模板化收束等特征可能消失，判定准确率将显著下降
3. 前提B17不成立（判定者可通过人机对照或统计比较才能识别特征）：清单中未纳入的需对照才能显现的特征将无法用于单篇盲读判定，需补充单篇可独立辨识的特征维度
4. 前提B21不成立（判定参照系非当代标准白话小说）：翻译腔、方言、仿古小说的AI味判定规则将失效，需匹配对应文体的专属参照系
5. 前提B24不成立（第一人称/现在时/书信日记体的豁免规则不适用）：表层叙述特征将被误判为AI味，导致误判率上升
6. 前提B26不成立（不同读者对AI味特征的敏感度与误判率存在差异）：当前通用清单的误判率将上升，需按读者画像（网文读者/纯文学读者/非母语读者等）分层制定判定规则
7. 约束B6不成立（文本长度/题材/语言发生改变）：高频重复关联词套用、冗余修饰句占比超15
