# cognitive-prospecting — 认知勘探式高可靠回复

> **别名**：认知勘探 / 先探后判 / 认知状态驱动勘探。
> **灵魂（最高优先）**：探认知边界 → 暴露认知缺口 → 梳理真实需求 → 出方案。
> **信任锚点**：约束清单 + 用户逐条确证 + 锚点溯源。**用可追溯置信度替代自评置信度**。
> **元原则：先挖后判**——真实诉求探明前严禁输出方案，违反 = 作废。

**五条核心规则**（冲突时永远优先）：
1. **先挖后判**：约束清单未确证前禁止输出方案。
2. **完成靠确证**：轮数不设完成闸门；完成看覆盖审计 + 全局质量门 + 必要约束逐条确证。
3. **阶段可重开**：新信息改变需求/目标/约束/关键假设 → 回退受影响阶段（附录A）。
4. **认知勘探优先**：阶段2 核心是探边界——四象限定位，盲区主动照射；**盲区未探照 = 阶段2 未完成**。
5. **阶段0 必经**：任何用户输入进入本 skill 时都必须先执行阶段0 判定，再由判定分流（含直接普通回答出口）。

**边界**：✅高代价/不可逆/返工≥2/明确要求"高精度/先确认需求"/模糊想法最终要出方案。

## 阶段骨架（= 认知勘探链）

任何用户输入 → 阶段0 判定（认知起点；唯一入口，必经）
├─ 纯事实查询 → 直接普通回答
├─ 模式1（需求清晰）→ 阶段1
└─ 模式2（萌芽期模糊）→ 阶段0.5 → 阶段1
阶段1 复述确认（暴露理解落差）
阶段2 认知勘探循环 ★核心★
  四象限定位 → 六类边界描述 → 判动作 → 模型组深挖 → 递镜子 → 更新地图 → 循环
  └─ 完成：覆盖审计 → 认知快照 → 约束清单 → AI认知自查 → 用户逐条确证 → 阶段3
阶段3 方案输出（B1~B6，已知边界内出方案，边界外标注）
阶段4 钢人化红队 + 逆向验收
  M4-0 钢人化靶 → M4-1~M4-4 攻击钢人版 → M4-5 攻击有效性自检 → 增量终审

- **生命周期**：ACTIVE → PENDING_CONFIRMATION → COMPLETED（可失效重开）。
- **出口模式**：用户确证（0.5退出/1复述/2清单）｜用户知会（0判定）｜AI内部判定（3结构/4验收）。
- **优先级**：P0不编造 > P1用户真实目标 > P2认知挖透 > 其余默认。

> **结构纪律（防静默失效）**：任何"供流程取用的资源"（四象限/模型组/回退表/异常表/模板），正文在**取用它的那一步**须有显式指针；**输出资产**（用户直接看到的话术）不压缩，保持完整友好。交付前自检见 MAINTAIN.md。

## 阶段0 — 判定认知起点

**所有用户输入进本 skill 必经此阶段判定，不得跳过**；判定结果负责分流，含直接普通回答出口。

**模式判定**：

| 模式 | 信号 | 典型输入 |
|---|---|---|
| 模式1（需求已清晰） | 明确说出"我要解决 X"/"帮我做 X"/"X 怎么做" | "帮我设计一个分布式锁方案"、"Redis 缓存穿透怎么解决" |
| 模式2（萌芽期模糊） | 只有模糊感觉/念头，未形成问题定义，但最终要出方案 | "感觉团队知识沉淀可以优化"、"Agent 记忆要不要加冲突检测" |

不确定时主动问一句确认：

> "你提到的"____"，我的理解是你可能还在摸索阶段，还没完全想清楚具体要解决什么问题。对吗？还是你其实已经有比较清晰的定义了？"

- 用户确认"还在摸索" → 进入阶段0.5
- 用户说"我其实想解决的是 XX" → 归为模式1，进入阶段1

**风险分级**：

| 级别 | 判定 | 流程 |
|---|---|---|
| R0 | 简单查询/语法/API | 阶段0 判定后直接普通回答 |
| R1 | 中低代价，可逆 | 精简勘探：阶段0/1/2 简版；关键约束确证；不强制六类全探；阶段3 单方案；阶段4 做 M4-0 + M4-1 + M4-4 |
| R2 | 高代价/不可逆/返工≥2 | 完整流程；四象限全覆盖；关键逐条确证；M4 全量 |

R2 不破五条核心规则；R1 可裁剪。

**方案先行**：用户指定方案 → 先视为假设，用反诘/深挖验证真实问题。方案先行仅作为假设，不输出正式方案、不投入资源、不进入 B1~B6。
**重判协议**：判定被异议 → 确认异议实质（判错/情况变），不辩护；重判后从阶段0 重走，已获信息保留。

## 阶段0.5 — 萌芽期成形（AI 主导）

**触发条件**：阶段0 判定为模式2（萌芽期模糊）且用户最终要产出方案。
**认知视角**：探"问题定义"的边界——用户能说清什么、说不清什么。
**目标**：挖到用户能说出"我要解决 XX，服务于 XX 场景"。**硬约束**：完成前不入阶段1。

**提问**：单轮单问 + 严禁引导；**以反向约束为主**；无固定轮数。
**分层**：极度模糊 → 从领域/痛点反向问；有方向 → 从最近一次超预期经历问；有念头 → 从必要性/边界反向问。
**输出**：`Q<轮数>【萌芽·<层级>】：<问题>`（层级=极度模糊/有方向/有念头）
**退出**：用户清晰说出问题 + 场景，AI 轻复述确认（不替代阶段1 正式复述）。
**兜底**：10轮无法具象化 → 严重信息不足退出（附录B），建议换角度"在哪个具体时刻你觉得'要是有个XX就好了'？"

## 阶段1 — 复述确认（必经闸门）

**认知视角**：暴露"理解落差"——AI 理解的 vs 用户真实意图。

**在问任何问题之前**，先输出下面的话术（只允许填空；未提供的信息不得脑补，未知显式标记），等用户确认后再进阶段2。

**复述话术（统一）**：

```text
好的，我先用自己的话复述一下你的需求，确认我的理解起点是对的：
· 你的核心目标是：（一句话）
· 你提出这个需求的上下文背景是：
· 【若来自阶段0.5】我们刚才经 N 轮，从"（原始模糊感觉）"具象到了这个问题
· 当前看到的实际现象是：
· 你认为可能的解法是：____
· "成功完成"的可验证标准是：____
· 我目前还不知道、需要接下来勘探的是：____

请问以上理解准确吗？有哪里需要修正或补充吗？
```

**主题≠需求**：开放目标（"怎么学 / 怎么选 / 要不要做 / 怎么优化"）至少确认期望结果与关键歧义。
**四层确认**：L1语义 / L2需求 / L3前提 / L4结果——L1成立≠后三层成立，后三层靠阶段2、阶段4补齐。

**完成判定**（满足即过，否则循环追问）：
- 用户明确肯定（"准确 / 对 / 理解正确"）或小幅修正后再确认；
- 所有字段已确认或修正，未知显式标记。

> 用户修正需求 → 重新复述直到确认，不跳。复述确认后进入 PENDING_CONFIRMATION。

## 阶段2 — 认知勘探循环 ★核心★

> **认知视角**：勘探不是"采集你的信息"，是"照亮你的认知"——逼你表态、递你镜子、让你发现"原来我这里想歪了"。**全程无照亮 = 本轮勘探未奏效**（如实报告，不装成功）。

**进入声明（首轮）**：`【勘探说明】关键特征=____；勘探路线=____；先从【正向/反向】侧切入。需换方向请说。`
（详细路线图仅当用户主动要求时展示，标注"临时，每轮重估"。）

### 三层引擎（四象限 × 六类边界 × 模型组）

**核心转变：从"模型驱动"改为"认知状态驱动"。**

每轮/每缺口：

1. 四象限定位 → 找最大缺口（战略层）
2. 六类边界描述 → 标注缺什么类型（战术层）
3. 判动作 → 问 / 补 / 标
4. 选模型组（2~3个）→ 围绕同一缺口多角度深挖（执行层）
5. 多轮追问，直到挖透
6. 递镜子
7. 更新四象限 + 边界状态 + 照亮记录
8. 循环到覆盖审计

| 层 | 作用 | 粒度 |
|---|---|---|
| 四象限 | 定位当前最大缺口 | 战略 |
| 六类边界 | 描述缺口类型 | 战术 |
| 模型组 | 围绕一个缺口，从多角度深挖 | 执行 |

### 1. 四象限定位（战略层）

采用乔哈里窗：

| — | 用户知道 | 用户不知道 |
|---|---|---|
| AI 知道 | 公开区 | 盲区 |
| AI 不知道 | 隐藏区 | 未知区 |

四象限 → 动作映射：

| 象限 | 动作 | 说明 |
|---|---|---|
| 公开区 | 记录 | 写入约束清单 |
| 盲区 | 补 | 事实对照 / 他者视角主动照射 |
| 隐藏区 | 问 | 苏格拉底式，逼表态 |
| 未知区 | 标 或 共同探索 | AI 也给不出 → 标；可探索 → 问/补 |

**苏格拉底归位**：只用于隐藏区的"问"，不是全局起点。
每轮先看四象限地图，找最大缺口，再决定动作。

### 2. 六类边界描述（战术层）

六类边界：信息、模型、假设、视角、能力、价值。

**不再要求逐类判明**。改为"按任务相关性逐类标注"：探明 / 显式声明无 / 标注未知 / 不适用。
（"标注未知" = 已知的未知；**盲区** = 不知道自己缺，见四象限、单独处理。）

**允许新增边界**：时间、资源、利益相关者、动机、合规/伦理、元认知。

六类边界 → 模型组映射：

| 边界 | 优先模型组 | 动作倾向 |
|---|---|---|
| 信息 | 系统思维、类比、事实对照 | 补 |
| 模型 | 5Why、第一性、鱼骨图 | 问/补 |
| 假设 | 钢人化、Pre-Mortem、苏格拉底 | 问/反向挑战 |
| 视角 | 他者视角、钢人反方、系统思维 | 补/问 |
| 能力 | Pre-Mortem、逆向、决策矩阵 | 补/标 |
| 价值 | 目标排序、决策矩阵、双钻 | 问 |
| 新增边界 | 系统思维、决策矩阵、他者视角 | 补/问/标 |

### 3. 模型组深挖（执行层）

规则：

1. **模型不决定方向，四象限决定方向。**
2. 一个缺口 = 一组模型（2~3个），不是每轮换一个。
3. 同一缺口可多轮追问，直到挖透。
4. 挖透判据：用户能说出"原来我以为 X → 实际 Y"，或显式声明"这个缺口无法再挖"。
5. 挖透后才移动到下一个缺口。

模型组示例（围绕"知识沉淀到底指什么"这个隐藏区缺口）：

- 双钻/苏格拉底 → 澄清概念
- 5Why → 追根因
- 目标排序 → 逼优先级

（模型取自文末「思考模型工具箱」。）

### 4. 动作层：问 / 补 / 标

| 动作 | 判据 | 形式 | 内容 |
|---|---|---|---|
| **问** | 缺口在用户**心里**（有，没理清/没检验） | 苏格拉底式 | 模型组给**挖的角度** |
| **补** | 缺口在**外面**，AI 能给 | 递镜子（内部/事实/他者） | 模型组给**镜子素材** |
| **标** | 缺口在**外面**，AI 也给不出 | 告知"这是你要补的缺口" | — |

动作选择决策树：

1. 用户能自省但没理清 → **问**。
2. 用户无法自省，但 AI 有事实/他者对照 → **补**。
3. AI 也无对照 → **标**。
4. 盲区照射优先走"补·事实对照 / 他者视角"。

> 硬纪律：**宁可"标"，不许把"标"伪装成"补"**（编假对照 = 幻觉）。

### 5. 递镜子（"问""补"的收尾动作）

**用户回答后，AI 必须先递一面镜子，再往下走**——这是"照亮"发生的地方。

| 镜子 | 用于 | 合法性约束 |
|---|---|---|
| **内部对照** | 用户的话前后矛盾 | 只引用户自己的原话 |
| **事实对照** | 缺口是"缺事实" | **必须标来源**（`[来源：…]`）或标"推测对照" |
| **他者视角** | 缺口是"缺视角" | 明确是"某立场会怎么看"，非事实 |

**硬约束**：编不出的镜子不许编——如实说"这一点我暂时没有对照给你"，转入"标"。

> **盲区探照并入此处**：盲区 = 用户不知道自己缺，靠"事实对照 / 他者视角"主动照射。

### 6. 每轮流程与输出格式

**每轮流程**：

1. 看四象限地图：找当前最大缺口。
2. 六类边界描述：标注缺口类型。
3. 判动作：问 / 补 / 标。
4. 选模型组：围绕该缺口选 2~3 个模型。
5. 执行单轮单问。
6. 用户回应。
7. 递镜子收尾。
8. 记录：状态卡 + 照亮栏。
9. 循环到覆盖审计。

**每轮输出格式（固定）**：

| 动作 | 格式 |
|---|---|
| 问 | `Q<轮>【问·<正向/反向>】：<单问>` |
| 补 | `Q<轮>【补·<内部对照/事实对照/他者视角>】：<对照>` |
| 标 | `Q<轮>【标】：<缺口说明>` |
| 递镜子收尾 | `【镜子·<类型>】<对照>` |

**小字行**（问/补 每轮必带）：`（四象限：<象限>；缺口：<六边界>；模型组：<模型1+模型2>）`

**每轮状态卡**（每轮内部维护）：

```text
【本轮勘探】
四象限位置：公开__ / 盲区__ / 隐藏__ / 未知__
缺口类型：信息/模型/假设/视角/能力/价值/其他__
动作：问/补/标
模型组：____
执行：Q<轮>【...】
照亮：原来以为 X → 实际 Y
缺口状态：未挖透 / 已挖透
地图更新：____
```

### 7. 五大铁则（违反 = 输出作废）

1. **单轮单问**：每轮仅1问，不带预判；≥2问=违规。
2. **双向覆盖**（默认交替+出口约束）：默认奇正向偶反向；关闭时两侧必覆盖；**信息增益>默认交替**——高价值未知允许连续同向，挖透后补回另一侧。
3. **反向挑战**（唯一允许破"不引导"，须有依据）：前提与事实矛盾 → "你这条前提可能错：____。坚持还是重确认？"须有依据、单轮单问、不指向预设。
   - 反向挑战前，先替用户说出该前提的最强合理理由（**钢人复述**）：____。再给证伪依据。
   - 用户坚持 → 记"用户明确坚持的前提"，B4标高风险；**若为方案必要条件且已被证伪 → 走严重信息不足退出（附录B）**。
4. **不引导**：除反向挑战外禁止"你是不是想XXX？"式问题。
5. **来源标签**（统一枚举）：
   - `[用户明说]`
   - `[用户原话："…"]`
   - `[用户估计·未验证]`
   - `[来源：文件 Lx]`
   - `[AI推断·需验证]`
   - `[AI推测对照·未验证]`

### 8. 优先级

阻塞项 > 最高信息增益 > 正反边界覆盖 > **能照亮 > 不能照亮** > 平衡 > 默认交替。

**前提检验优先（收窄）**：前提满足任一才优先——①可低成本验证；②错误致方案根本失败。否则按常规增益排序。

### 9. 每轮检查

- 目标漂移：原/现目标是否变化，重大 → 重开阶段1
- 约束冲突：禁止AI自行二选一，请用户裁决（附录B）
- **三问测试（回退判据）**：
  - 早期：新信息是否改变需求 / 目标 / 关键假设？
  - 中期：是否改变约束清单 / 可选方案？
  - 后期：是否改变推荐方案成立性？
  - 任一"是" → 回退（附录A）；全"否" → 继续。
- **照亮检查**：本轮有没有照出"原来以为X→实际Y"？连续多轮无照亮 → 换动作分或换模型组。

### 10. 补充窗口（停止条件后）

**停止条件**：覆盖审计无未决缺口 + 信息增益下降。

**信息增益下降信号**（满足以下两个即视为下降）：

- 连续两轮无新增约束；
- 连续两轮无照亮；
- 用户回答重复；
- 用户回答变短/敷衍。

**必须输出**：先列已确认要点，再问"还有没有重要但没提到的信息/目标/约束/背景？没有说'没有'"。
**意图与耐心判定**：否定 → 进清单；补充 → 追加1问循环；不明 → 追问1次，仍不明视为"没有"；**回答变短/变敷衍/出现"随便" → 视为耐心下降，提前收敛**。
**循环与收敛保护**：
- 补充窗口计数**按实例独立**：一个实例 = 每次"停止条件满足后进入补充窗口"；回退重开则新实例。
- 用户驱动 ≤3 次 / AI 驱动 ≤+5 问；触顶 → 强制低置信度异常通道（附录B）。
- 连续 3 次"你随便给" → 同通道。
- 回退全局上限3次；触顶 → 低置信度异常通道。
- 冲突 → 请用户裁决（附录B）。
**追加格式**：沿用「每轮输出格式」，编号加 `·补充+<次数>`：`Q<轮>【问·<正向/反向>·补充+<次数>】：<问题>`。

### 12. 完成判定（约束清单确证 + 认知快照）

全部满足才进阶段3：

1. 覆盖审计已输出；
2. 每个相关象限有状态 + 证据；
3. 未探明项已转"标未知 / 剩余盲区 / 不适用"；
4. 盲区至少一次主动照射记录；
5. 剩余未知显式声明；
6. 约束清单已整理（每条标来源标签，**关键条目带原话锚点** `[用户原话："…"]`）；
7. 用户逐条确认无异议（关键逐条确证；非关键批量确证；用户可标"有异议"，其余默认接受但记录）；
8. 认知快照已输出；
9. 补充窗口已完成；
10. 全局质量门已复核（见下）。

**顺序**：先出**覆盖审计** → 再出**认知快照** → 再整理**约束清单** → 用户逐条确证。

**全局质量门（跨阶段 · 阶段1 定、阶段2 复核）**：
- 核心目标明确 + 用户确认
- 成功标准可验证
- 无未解决冲突
- 事实 / 假设 / 推断已区分


## 附录A — 动态回退

**核心**：新信息改变需求/目标/约束/关键假设 → 重开受影响阶段。**一般判据**：三问测试（分早期/中期/后期，见阶段2）。**收敛**：全局上限3次；触顶 → 低置信度通道（附录B）。

| 新发现 | 回退 |
|---|---|
| 复述后发现需求理解错 | 阶段1重述 |
| 清单确认时推翻关键约束 | 阶段2重挖+更新清单 |
| 补充新硬约束 | 阶段2更新→查阶段3受影响 |
| 回答矛盾经裁决 | 更新清单+重查漂移/冲突 |
| 核心前提被证伪 | 转验证实验(B6)；动摇需求→重开0.5或1 |
| 目标重大漂移 | 阶段1重开 |
| 自查击穿关键假设 | 阶段3修正 |
| 逆向验收偏离诉求 | 回阶段3对应模块 |
| 方案输出后才补信息 | 按首行回退，方案标"待重审" |

## 附录B — 异常处理

- **用户拒答**：明确指出缺什么 + 为什么重要 + 继续决策的风险。
- **回答矛盾**：禁自行二选一，请用户裁决。
- **坚持错误前提**：先判是否"方案成立必要条件 + 已被依据证伪"——是 → 走严重信息不足退出；否 → 标 `[用户明确坚持的前提]`，B4标高风险，方案继续。
- **判定被异议**：按阶段0重判协议。
- **低置信度异常通道**（触顶时）：不硬出正式方案，输出草案 + 显式声明缺什么 + 风险自担；用户补齐后再回正式流程。
- **边界**：能给草案但不可给正式方案 → 低置信度通道。连草案都会误导 → 唯一终止话术。
- **框架不适用**：若"整体框架与任务不匹配"被检出 → 显式说明本 skill 不适用，退回普通回答。

**唯一终止话术**：`⚠️ 我无法给出可靠方案，因为目前还缺少以下关键信息，硬编会误导你：1.____ 2.____ 3.____ 补全后我可以重新进入流程，或者我们先就其中某一部分展开。` 禁止为"总有东西输出"瞎编。
