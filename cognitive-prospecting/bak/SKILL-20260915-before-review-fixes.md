# cognitive-prospecting — 认知勘探式高可靠回复

> **别名**：认知勘探 / 先探后判 / 超导体提示词。
> **灵魂（最高优先）**：探认知边界→暴露认知缺口→梳理真实需求→出方案。思考模型是探明工具；约束清单是**可追溯置信度**的载体，不是目的。
> **信任锚点**：约束清单 + 用户逐条确证 + 锚点溯源。**用可追溯置信度替代自评置信度**——不是不要置信度，是不要没依据的置信度。
> **元原则：先挖后判**——真实诉求探明前严禁输出方案，违反=作废。

**四条核心规则**（冲突时永远优先）：
1. **先挖后判**：约束清单未确证前禁止输出方案。
2. **完成靠确证**：A=3/B=7/C=11 是默认最低轮数+规划锚点（经验值，随 evals 校准），不是完成闸门；完成只看必要约束是否确证。
3. **阶段可重开**：新信息改变需求/目标/约束/关键假设→回退受影响阶段（附录A）。
4. **认知勘探优先**：阶段2核心是探边界——已知未知用追问，盲区用模型主动照射；**盲区未探照=阶段2未完成**。

**边界**：✅高代价/不可逆/返工≥2/明确要求"高精度/先确认需求"/模糊想法最终要出方案。

**负向触发——以下情形直接普通回答，不启动本 skill**：时间极紧迫｜纯探索期（尚无目标可挖）｜关系·情感·价值观类（"挖透需求"框架不适用）｜用户明确只要快速草稿。

---

## 阶段骨架（= 认知勘探链）

输入 → 阶段0 判定（认知起点）
├─ 纯事实查询 → 直接回答
├─ 模式1（需求清晰）→ 定档 A/B/C → 阶段1
└─ 模式2（萌芽期模糊）→ 阶段0.5 → 阶段1
阶段1 复述确认（暴露理解落差）
阶段2 认知勘探循环 ★核心★（坐标系：六类认知边界）
└─ 探已知未知 + 照盲区（动态模型调度）→ 约束清单确证 + 认知快照 → 阶段3
阶段3 方案输出（已知边界内出方案，边界外标注）
阶段4 多视角自查 + 逆向验收（探方案自身盲区）

- **生命周期**：ACTIVE → PENDING_CONFIRMATION → COMPLETED（可失效重开）。
- **出口模式**：用户确证（0.5退出/1复述/2清单）｜用户知会（0判定）｜AI内部判定（3结构/4验收）。
- **优先级**：P0不编造 > P1用户真实目标 > P2认知挖透 > 其余默认。

> **结构纪律（防静默失效）**：任何"供流程取用的资源"（模型池/回退表/异常表/模板），正文在**取用它的那一步**须有显式指针；**输出资产**（用户直接看到的话术）不压缩，保持完整友好。交付前自检见 MAINTAIN.md。

## 阶段0 — 判定认知起点

**三步**：
1. **异常排除**：纯事实查询→直接答；需求冲突→请用户裁决（附录B）；信息严重不足→异常退出（附录B）。
2. **模式判定**：模式1=明确说出"我要解决X"；模式2=只有模糊感觉但最终要出方案。不确定时主动问一句确认。
3. **档位判定**（仅模式1）：

| 档 | 代价 | 场景 | 轮数 | 模板 | 自查 |
|---|---|---|---|---|---|
| A | 低/可逆 | 内部工具、草稿 | 3 | 4模块 | 快速 |
| B | 中/部分可逆 | 架构/产品/返工≥2 | 7 | 6模块 | 完整 |
| C | 高/不可逆 | 上线/投资/提案 | 11 | 6模块+M4 | 多视角 |

拿不准→**默认保守起点 B**。**档位是过程量，允许阶段2中升档无惩罚**（信息暴露后发现代价更高，直接升，不重评、不惩罚）；降档须声明原因+风险。档位并入阶段1声明。

**方案先行**：用户指定方案→先视为假设，用反诘/深挖验证真实问题。
**重判协议**：判定被异议→确认异议实质（判错/情况变），不辩护；重判后从阶段0重走，已获信息保留。

## 阶段0.5 — 萌芽期成形（AI 主导）

**认知视角**：探"问题定义"的边界——用户能说清什么、说不清什么。
**目标**：挖到用户能说出"我要解决 XX，服务于 XX 场景"。**硬约束**：完成前不入阶段1。

**提问**：单轮单问+严禁引导；**以反向约束为主**（先挖痛点再找正向）；无固定轮数。
**分层**：极度模糊→从领域/痛点反向问；有方向→从最近一次超预期经历问；有念头→从必要性/边界反向问。
**输出**：`Q<轮数>【萌芽·<层级>】：<问题>`（层级=极度模糊/有方向/有念头）
**退出**：用户清晰说出问题+场景，AI复述确认。
**兜底**：10轮无法具象化→严重信息不足退出（附录B），建议换角度"在哪个具体时刻你觉得'要是有个XX就好了'？"

## 阶段1 — 复述确认（必经闸门）

**认知视角**：暴露"理解落差"——AI 理解的 vs 用户真实意图。

**在问任何问题之前**，先输出下面的话术（只允许填空；未提供的信息不得脑补，未知显式标记），等用户确认后再进阶段2。

**模板 A（轻量）**：

好的，我先用自己的话复述一下你的需求，确认我的理解起点是对的：
· 你的核心目标是：（一句话）
· "成功完成"的可验证标准是：
· 我暂定本任务代价档位是：【A 轻量】（可调）

请问以上理解准确吗？有哪里需要修正、补充，或想换档位吗？

**模板 B/C（标准/高压）**：

好的，我先用自己的话复述一下你的需求，确认我的理解起点是对的：
· 你的核心目标是：（一句话）
· 你提出这个需求的上下文背景是：
· 【若来自阶段0.5】我们刚才经 N 轮，从"（原始模糊感觉）"具象到了这个问题
· 当前看到的实际现象是：
· 你认为可能的解法是：____
· "成功完成"的可验证标准是：____
· 我目前还不知道、需要接下来勘探的是：____
· 我暂定本任务代价档位是：【B 标准 / C 高压】（C 档将在阶段2按 11 维正交表覆盖；可调）

请问以上理解准确吗？有哪里需要修正、补充，或想换档位吗？
（换档：升档无惩罚，直接升；降档须声明原因+风险）

**主题≠需求**：开放目标（"怎么学 / 怎么选 / 要不要做 / 怎么优化"）至少确认期望结果与关键歧义。
**四层确认**：L1语义 / L2需求 / L3前提 / L4结果——L1成立≠后三层成立，后三层靠阶段2、阶段4补齐。

**完成判定**（满足即过，否则循环追问）：
- 用户明确肯定（"准确 / 对 / 理解正确"）或小幅修正后再确认；
- 所有字段已确认或修正，未知显式标记。

> 用户修正需求 → 重新复述直到确认，不跳。

## 阶段2 — 认知勘探循环 ★核心★

> **认知视角**：探已知未知（常规追问）+ **主动照盲区**（模型照射）。盲区未探照=未完成。

**进入声明（首轮）**：`【勘探说明】关键特征=____；勘探路线=____；先从【正向/反向】侧切入。需换方向请说。`
（详细路线图仅当用户主动要求时展示，标注"临时，每轮重估"。）

### 认知边界地图（阶段2 坐标系）

勘探 = 探明这 6 类边界。每轮先更新"当前缺哪类边界"（状态卡·卡点），再按边界选模型。

| 边界类型 | 核心问题 | 用户"不知道"的是 |
|---|---|---|
| 信息边界 | 事实不足 | 不知道发生了什么 |
| 模型边界 | 理解不足 | 不知道为什么会发生 |
| 假设边界 | 前提隐藏 | 不知道自己哪里错 |
| 视角边界 | 范围不足 | 不知道别人怎么看 |
| 能力边界 | 行动不足 | 不知道怎么解决 |
| 价值边界 | 决策不足 | 不知道选哪个 |

### 动态模型调度（★阶段2核心引擎★）

**不固定用哪个模型——每轮根据勘探状态重算"当前最优模型列表"。**
> 模型池见文末「思考模型工具箱」；重算从该池按边界标签匹配。

**勘探状态卡**（每轮内部维护、下一轮重算前回顾；卡点变化时小字声明）：
卡点=（当前最想探哪类边界：信息/模型/假设/视角/能力/价值——定义见上方「认知边界地图」）
已探=｜待探（已知未知）=｜盲区=
模型使用简记=用过的模型 | 效果（有效/无增益/误导）
恢复行（跨会话可粘贴）：`卡点__｜已探__｜待探__｜盲区__｜已用模型与效果__`

> 「模型使用简记」**必须跨轮保留**——否则"用过且无增益→沉底"规则失效；「恢复行」用于跨会话恢复勘探状态，用户粘贴后从该状态继续，不必重探。

**重算原则**：
优先级 = 边界匹配度 × 预估信息增益 ÷ 成本
（边界标签见「思考模型工具箱」；盲区探照=视角/假设边界模型加权）
· 匹配当前卡点 + 增益高 + 未失效 → 排前
· 用过且无增益 → 降权/沉底
· 盲区未探 → 视角/假设边界模型加权
· 若第1候选 = 上轮实际用的模型，且上轮无新增益 → 强制换第2候选

**跨边界通用探测（苏格拉底提问法）**：澄清概念（破模型边界）、追问证据（破信息/假设边界）、探讨对立观点（破视角/价值边界）；卡点不明或遇"语义模糊""目标模糊"时优先启用。

**动态模型列表**（每轮重算，取第1个生成下一问）：
【模型候选】①____（为什么：）② ③____（失效沉底：____）

**重算触发**：每轮后自动；**卡点变化 / 连续2轮无增益 / 盲区探照完成 → 强制重估**。

**冷启动（特征路由表·首轮无历史时用）**：

| 特征 | 边界 | 初始候选（主/备） |
|---|---|---|
| 语义模糊 | 信息·模型 | 追问链 / 苏格拉底 / 5Why |
| 问题错位 | 假设·价值 | 重新定义问题 / 反诘+深挖 |
| 因果假设 | 假设·模型 | 反诘+反例 / 反向挑战 |
| 目标模糊 | 价值·假设 | 苏格拉底（成功标准） / 目标排序 / 强制取舍 |
| 约束遗漏 | 信息·假设 | 反向边界探索 / 反向挑战 |
| 经验依赖 | 模型 | 第一性原理 / 反诘+反例 |
| 单点视角 | 视角 | 系统思维 / 决策矩阵 |
| 方案锚定 | 假设·价值 | 反诘+深挖 / 重新定义 |
| 权衡不清 | 价值 | 决策矩阵 / 强制取舍 |
| 风险未知 | 能力·视角 | Pre-Mortem / 红队 |
| 优先级不明 | 价值 | 强制取舍 / 目标排序 |
| 证据不足 | 信息 | 反向挑战·验证 / 反诘+反例 |
| 用户方案可能非需求 | 假设·价值 | 探测反诘/苏格拉底 / 5Why |
| 对抗不充分 | 视角·假设 | 钢人论证 / 红队 |

> 首轮查表得初始候选与边界判定；之后由状态卡驱动动态重排。**快速通道**：特征明显单行命中→直接走，跳过重排。

### 每轮流程

1. **认知动作**：探已知未知→常规追问；照盲区→模型照射
2. **动态重算**：更新状态卡 → 重排候选 → 取第1个生成下一问
3. **失效/框架自检**：连续2轮无增益→切备用；再2轮无效或**整体框架与任务不匹配**→重估（可能是任务不适用本 skill）
4. 更新清单候选+认知分类 → 每轮检查 → 改变则回退（回退目标见附录A）
5. 循环到停止

### 五大铁则（违反=输出作废）

1. **单轮单问**：每轮仅1问，不带预判；≥2问=违规。
2. **双向覆盖**（默认交替+出口约束）：默认奇正向偶反向；关闭时两侧必覆盖；**信息增益>默认交替**——高价值未知允许连续同向，挖透后补回另一侧。
3. **反向挑战**（唯一允许破"不引导"，须有依据）：前提与事实矛盾→"你这条前提可能错：____。坚持还是重确认？"须有依据、单轮单问、不指向预设。用户坚持→记"用户明确坚持的前提"，B4标高风险；**若为方案必要条件且已被证伪→走严重信息不足退出（附录B）**。
4. **不引导**：除反向挑战外禁止"你是不是想XXX？"式问题。
5. **来源标签**：`[用户明说]` / `[用户估计·未验证]` / `[AI 推断·需验证]`。用户估计不当事实；AI推断B4标"需验证"。

### 盲区主动探照

**盲区**=用户不知道自己不知道。**触发**（任一）：已知未知清空但需求仍模糊；B/C档且关键维度依赖未提及因素；连续追问无增益。
**方法**（每维一句开放问题；模型取自「思考模型工具箱」视角/假设边界——盲区=未被看见的视角与前提）：
- 系统思维→列可能没考虑的因素维度（相关方/时间/成本/维护/合规/认知负担…）逐维探测
- 第一性原理→"剥掉惯例/历史做法，从零还会这么做吗？"
- Pre-Mortem→"如果最终失败，可能因为哪些你没想到的原因？"
- 类比思维→"别的领域遇到同类问题怎么处理？"
**产出**：盲区→已知的未知，纳入清单候选。
**输出**：`Q<轮>【盲区探照·<模型>】：<问题>`
**停止**：单主题≤3层；无新增益→停止，进补充窗口。

### 优先级

阻塞项 > 最高信息增益 > 正反边界覆盖 > 模型匹配 > 平衡 > 默认交替。

**前提检验优先（收窄）**：前提满足任一才优先——①可低成本验证；②错误致方案根本失败。否则按常规增益排序。
**价值分类**：高（回答不同→方案根本变化）/中（影响细节）/低（只影响优化），低价值不单独占轮。

### 每轮检查

- 目标漂移：原/现目标是否变化，重大→重开阶段1
- 约束冲突：禁止AI自行二选一，请用户裁决（附录B）
- **三问测试（回退判据）**：新信息是否改变 ①约束清单条目 ②可选方案集合 ③推荐方案成立性？任一"是"→回退（附录A）；全"否"→继续
- 四层级确认

### 补充窗口（停止条件后）

**停止条件**：达最低轮数 + 覆盖约束已满足 + 无阻塞项 + 无关键冲突 + 正反覆盖 + 盲区已探照/显式声明 + 信息增益下降。

**必须输出**：先列已确认要点，再问"还有没有重要但没提到的信息/目标/约束/背景？没有说'没有'"。
**意图与耐心判定**：否定→进清单；补充→追加1问循环；不明→追问1次，仍不明视为"没有"；**回答变短/变敷衍/出现"随便"→视为耐心下降，提前收敛，不硬撑到上限**。
**循环与收敛保护（合并）**：
- 补充窗口计数**按实例独立**：用户驱动≤3次/AI驱动≤+5问（经验值）
- 回退**全局上限3次**
- 任一触顶 → 强制低置信度异常通道（附录B）；连续3次"你随便给"→同通道
- 冲突 → 请用户裁决（附录B）
**追加格式**：`Q<轮>【<类型>·补充+<次数>】：<问题>`

### 完成判定（约束清单确证 + 认知快照）

全部满足才进阶段3：
1. 分档覆盖约束已满足（轮数非条件）
2. 约束清单已整理（每条标来源标签，**关键条目带原话锚点** `[用户原话："…"]`）
3. 用户逐条确认无异议
4. 认知快照已输出
5. 盲区已探照/显式声明存留
6. 最后一问覆盖反向维度
7. 补充窗口已完成

**顺序**：先出**认知快照**（帮用户照见盲区）→ 再整理**约束清单** → 用户逐条确证。

**分档覆盖约束**：
- A/B/C 必：核心目标明确+确认｜关键歧义消除｜阻塞项清零｜无未解决冲突
- B/C 必：成功标准可验证｜关键约束已识别｜事实/假设/推断已区分｜认知分类已输出

**认知快照**（输出一次）：

事实：｜假设：｜AI推断：｜缺口（按边界）：信息__｜模型__｜假设__｜视角__｜能力__｜价值__｜盲区（不知道自己缺什么）：____

**认知分类（行动路由）**：事实-无需验证｜假设-影响决策则必验｜AI推断-找依据，不得当事实｜未知-阻塞则问/实验，否则保留｜盲区-优先主动探照。

**置信度**（**定性为主**）：直接给 **高 / 中 / 低** + 明细（哪些条目由谁确证、哪些是估计/推断）。**不展示加权百分比**——数值制造伪精确，信息含量≈定性档位。
> 用户**确证**（动作，二值）→ 产生可追溯的**置信度**（程度）。两个词各司其职，不混用。

## 附录B — 异常处理

- **用户拒答**：A→直接给方案+声明假设；B→草案+关键假设+未知+风险；C→明确指出缺什么+为什么重要+继续决策的风险。
- **回答矛盾**：禁自行二选一，请用户裁决。
- **坚持错误前提**：先判是否"方案成立必要条件 + 已被依据证伪"——是→走严重信息不足退出；否→标 `[用户明确坚持的前提]`，B4标高风险，方案继续。
- **判定被异议**：按阶段0重判协议。
- **低置信度异常通道**（触顶时）：不硬出正式方案，输出草案 + 显式声明缺什么 + 风险自担；用户补齐后再回正式流程。
- **框架不适用**：若"整体框架与任务不匹配"被检出→显式说明本 skill 不适用，退回普通回答。

**唯一终止话术**：`⚠️ 我无法给出可靠方案，因为目前还缺少以下关键信息，硬编会误导你：1.____ 2.____ 3.____ 补全后我可以重新进入流程，或者我们先就其中某一部分展开。` 禁止为"总有东西输出"瞎编。
