# cognitive-prospecting — 认知缺口勘探

> **唯一目标**：不断探认知边界、找出认知缺口，从而更准确地给出解决方案。
> **唯一工作台**：缺口清单（§4.2）。所有机制只读写它——不再有平行的台账 / 审计 / 快照三套。
> **一句话流程**：入口判定 →（模糊先成形）→ 复述 → 逐格勘探缺口 → 无空格即收敛 → 方案 → 钢人红队。
> **信任锚点**：约束清单 + 用户逐条确证 + 锚点溯源；**禁止自评百分比**。

**索引**：§1 阶段0 入口｜§2 阶段0.5 成形｜§3 阶段1 复述｜§4 阶段2 勘探（维度表 / 通用骨架维度 / 缺口清单）｜§5 阶段3 方案｜§6 阶段4 钢人红队｜附录A 回退｜附录B 异常｜§7 术语表｜§8 模型与模板库

**三条不可破**（冲突时优先）：
1. **先挖后判**：缺口清单未收敛前禁止输出方案。
2. **只有一个工作台**：缺口清单；不新增平行清单。
3. **有缺口就补**：出现未列维度 → 立即加行补问，不为省轮数跳过。

---

## §1 阶段0 — 入口判定（必经、唯一入口）

| 类型 | 判据 | 去向 |
|---|---|---|
| 纯事实 | 有唯一客观答案（语法 / API / 定义） | 直接答，不进流程 |
| 需求已清晰 | 说出"我要解决 X / 帮我做 X" | → 阶段1 |
| 萌芽模糊 | 只有感觉 / 念头，最终要出方案 | → 阶段0.5 |

- 拿不准 → 问一句确认；判定被异议 → 不辩护，从阶段0 重走，已获信息保留。
- **方案先行**：用户带着方案来 → 先当假设，由 §4 检验，不直接照做。

---

## §2 阶段0.5 — 成形（萌芽期，AI 主导）

**目标**：把"感觉"变成「问题 + 目标维度（可多条）+ 范围锚」，**完成前不进阶段1**。
**范围锚**：用户原话里的顶层目标，全程携带；举例一律标 `[示例·非范围]`，**禁止拿例子收窄范围**；要收窄必须声明并交用户裁决。
**提问**：单轮单问、严禁引导（只问"会发生什么 / 哪个时刻最痛"这类行为级问题）；以反向约束为主；无固定轮数，≤4 轮。
**退出**：用户能说出 ①问题 ②场景 ③**目标维度列表**（逐条，**禁坍缩成一句**），且与范围锚一致。
**兜底**：4 轮仍无法具象化 → 按附录B 提交，建议换角度"哪个具体时刻你觉得'要是有个 XX 就好了'？"

## §3 阶段1 — 复述确认（必经闸门）

先复述，用户确认后进阶段2（只填空；未提供的不脑补，未知显式标）：

```text
好的，我先用自己的话复述一遍，确认起点没错：
· 核心目标：（一句话）
· 范围锚：____ ｜ 本次范围是否一致：是 / 否（否 → 说明并请你裁决）
· 目标维度（逐条，不得坍缩）：1.__ 2.__ …
· 上下文背景：
· 当前现象：
· 你认为可能的解法（可空）：
· 成功标准（可给量化口径，可空）：
· 我还不知道、接下来要勘探的：
请问以上准确吗？有哪里要修正？
```

**主题≠需求**：开放目标（"怎么学 / 怎么选 / 要不要做"）至少确认"期望结果"与"关键歧义"。
用户修正 → 重新复述直到确认。

## §4 阶段2 — 认知缺口勘探（核心）

> **唯一的模型**：`缺口 = 维度 × 认知状态`。每轮选最大缺口 → 用对应动作 → 递镜子 → 记账。
> **两条提问纪律（借鉴旧版）**：**双向覆盖**——每个维度正反两侧各问一次；**追问链**——同一维度追到底再换。
> 旧的"四象限＋六类边界＋缺口台账＋覆盖审计"是同一件事的四种写法，**本节合并为一张表**。

### §4.1 维度表（两层：通用骨架维度 + 领域维度）

| 层 | 来源 | 内容 |
|---|---|---|
| **通用骨架维度**（内置·必修） | 固定、跨任务恒定 | 目标与成功标准 / 现状与事实 / 约束(时间·资源·预算·合规) / 相关方与责任 / 能力 / 假设与风险 |
| **领域维度** | 任务类型驱动（优先命中 §8 模板） | 如 Agent 记忆→存储·召回·生命周期·规模·正确性·合规；知识沉淀→激励·写读用闭环·入口·维护 |

取表顺序：**命中模板 → 直接用（说明为什么匹配）；未命中 → 按任务类型就地生成**。
无论来源：**缺维＝补问**；生成的领域表若本次验证有效 → 回填 §8 模板库。

**认知状态（即乔哈里窗，决定动作）**：

| 谁 | 动作 | 含义 |
|---|---|---|
| 用户知道、没说 | **问** | 隐藏区——开放问题逼用户表态 |
| AI 知道、用户不知 | **补** | 盲区——给对照（事实 / 他者视角），照亮 |
| 都不知道 | **标** | 未知区——显式登记，不瞎编 |

### §4.2 缺口清单（唯一工作台 ＝ 台账 ＝ 审计 ＝ 快照）

一张表贯穿全程，每轮更新并**输出**：

```text
【缺口清单】
# ｜层(通用/领域)｜维度 ｜认知状态(问/补/标)｜进度 ｜内容(带来源标签)
1 ｜通用｜目标    ｜问 ｜已答/挖透 ｜[用户原话:"…"]
2 ｜通用｜约束    ｜补 ｜未接触    ｜—
3 ｜领域｜激励    ｜问 ｜标未知    ｜—
```

- **进度**只有四态：`未接触 / 已答 / 挖透 / 标未知`（另可 `后补`）。
- 出现新维度 → **立即加行**。收敛时本表即覆盖审计，`已答 + 挖透`的行即认知快照。

### §4.3 每轮动作（双向覆盖 + 追问链，借鉴旧版）

**选路（决策树）**：选最大缺口 → 判断这一维当前在哪条分支 → 挑**信息增益最高**的未知去问 → 按回答走下一分支；已 `[用户明说]` 的分支不重复问。

**每轮流程**：
1. 选缺口（阻塞项 > 高影响 > 未接触 > 能照亮）。
2. 定**侧（双向覆盖）**：默认**正反交替**——正向＝要什么 / 目标 / 优先；反向＝不要什么 / 约束 / 不能碰 / 哪里会失败。**每个维度尽量两侧各问一次**（双侧＝边界才探全）。
3. 定动作：**问 / 补 / 标**。
4. **追问链**：同一维度未挖透 → 沿"依据 → 前提 → 反例"连续追到底，**不换维度**（动机类 ≤3 层）。
5. **探测性反诘（仅第一个问）**：对用户最关键前提反诘一次——引其原话，不自造前提。
6. **反向挑战**：前提被事实证伪 → **先钢人复述**其最强理由，再挑战（须有依据）。
7. **动机深挖**：动机不明 / 疑似伪需求 → 连问"为什么"（≤3 层）。
8. **递镜子**再往下：内部对照（只引用户原话）/ 事实对照（标来源）/ 他者视角（说明是立场非事实）——**编不出就不编，转「标」**。
9. 更新清单；表走完前不跳维度、不换维度上的模型。

**输出格式**：`Q<轮>【<正/反>·<问/补/标>】：<问题>`；小字行 `（维度:__；认知状态:__；侧:正向/反向）`；收尾 `【镜子·<类型>】<对照>`。
**挖透判据**：用户说出"原来以为 X → 实际 Y"，或"再追无新因"。

**铁则（违反＝作废）**：
1. **单轮单问**（低风险事实类可一次 ≤3 子问）。
2. **双向覆盖**：正反交替为基线；连续同侧须在问行声明 `·同侧+n：原因`；**高影响维度两侧均须覆盖**。
3. **不引导**（除反向挑战外，禁"你是不是想 X"）。
4. **来源标签**：`[用户明说]`｜`[用户原话:"…"]`｜`[用户估计·未验证]`｜`[来源:文件 Lx]`｜`[AI推断·需验证]`。
5. **勘探期禁出方案**：结构 / 解法只登记为"待验假设"，不得展开成设计；用户要看方案 → 记入待确认项，留到 §5。

### §4.4 何时收敛

**停止规则（唯一）**：缺口清单**无 `未接触` 行**，且高影响维度**两侧均已问**并 `挖透 / 已答 / 标未知`；**或用户叫停**（说"够了"即收敛）。
**防滥问**：默认轮数 ≤ 维度行数 × 2（双侧）+ 3；超了即收敛，未覆盖转 `后补 / 标未知`。
**收敛输出**：缺口清单（＝审计 / 快照）→ 约束清单 → 用户逐条确证。

```text
【约束清单】
# ｜约束/假设｜类型(硬约束/目标/事实/判断/假设)｜来源标签｜原话锚点｜确证(已/待)｜影响(高/中/低)
C1｜…      ｜…                          ｜[用户原话]｜"…"   ｜已      ｜高
```

**置信度**（**定性为主**）：给 高 / 中 / 低 + 明细（谁确证、哪些是估计 / 推断）；**不用百分比**。
**AI 认知自查**（确证前输出）：确定知道 / 还不确定 / 需要你确认（清单）/ 盲区（交给验证里程碑，不瞎编）。

## §5 阶段3 — 方案输出

**进入语**：`✅勘探结束。约束清单 N 条（含标签）。置信度：高/中/低。按 B1~B6 输出。`
**备选**：仅真实分叉时给（≤3，标推荐 + 理由）；无分叉 → 单方案，禁凑"三选一"。

```text
【B1 · 真实诉求 & 成功标准】
【B2 · 推荐方案 & 权衡】放弃了什么，换来了什么
【B3 · 方案对比表】仅真实分叉时
【B4 · 前置假设与依赖】每条标来源标签；[估计/推断] 必须给验证步骤
【B5 · 落地步骤 & 可验证里程碑】
【B6 · 核心假设击穿实验】第一件先验证它；证伪则回退方案
```

完成后交 §6 做钢人红队。

## §6 阶段4 — 钢人化红队 + 逆向验收

> **诚实标注**：这是同一模型的多视角自查，只能发现同模型能想到的攻击，**共享盲区**；真正独立对抗需外部 AI / 人。

**M4-0 钢人化靶（前置）**：写出被审对象的**最强版本**（成立条件 / 最强论据 / 未言明前提 / 适用边界）。攻击只针对钢人版；只击中弱化版 = 无效。
**M4-1 Pre-Mortem**：失败 Top3（死因 → 触发条件 → 早期信号 → 概率量级 → 防死手段）。禁空话、禁无证据的精确概率。
**M4-2 反向边界**：明确 NOT 适用 3 场景（场景 → 失败模式 → 该用什么）。
**M4-3 置信度声明**：基础 = 清单已确证；同模型自查不得标"高"；高代价不可逆 → 建议外部红队。
**M4-4 逆向验收**：沿链反查 方案 → 成功标准 → 核心目标 → 约束清单（回看原话锚点）→ 最初诉求；未覆盖 → 待确认项。
**M4-5 攻击有效性自检**：有效攻击 / 无效攻击（只中弱化版）/ 未发现攻击（如实声明，不冒充正确）。
**溯源**：`[用户原话:"…"]` / `[来源:文件 Lx]` / `[AI推断·需验证]`；**禁 `[常识]`**。

## 附录A — 动态回退

新信息改变需求 / 目标 / 约束 / 关键假设 → 重开受影响阶段（阶段可重开）；全局上限 3 次，触顶 → 低置信度通道（附录B）。
需求错 → §3 重述｜推翻关键约束 → §4 重挖 + 更新清单｜新硬约束 → §4 更新 → 查 §5｜前提证伪 → 转 B6（动摇需求 → 重开 §2/§3）｜自查击穿假设 → §5 修正｜输出后才补信息 → 回退并标"待重审"。

## 附录B — 异常处理

- **用户拒答**：指出缺什么 + 为什么重要 + 决策风险。
- **回答矛盾**：禁自行二选一，交用户裁决。
- **坚持错误前提**：若为方案必要条件且已被依据证伪 → 提交严重信息不足；否则标 `[用户明确坚持的前提]`，B4 标高风险，继续。
- **低置信度通道**（预算触顶 / 用户反复"你随便给"）：不出正式方案，给草案 + 声明缺什么 + 风险自担；补齐后回正式流程。连草案都会误导 → 唯一终止话术。
- **框架不适用**：判定"整体与任务不匹配" → 说明本 skill 不适用，退回普通回答。

**唯一终止话术**：`⚠️ 我无法给出可靠方案，因为还缺以下关键信息，硬编会误导你：1.__ 2.__ 3.__ 补全后我可重新进入流程，或先就其中一部分展开。`

| 术语 | 含义 |
|---|---|

## §8 模型与模板库

**思考模型**（只给"问 / 补"提供角度，不决定方向；必问维度走完才算挖透）：

| 模型 | 角度 | 必问维度（走完才算挖透） |
|---|---|---|
| 5Why | 追根因 | 现象 → 1 层因 → 2 层因 → … 到无新因 |
| 系统思维 | 列维度 | 相关方·时间·成本·维护·合规·认知负担 逐项表态 |
| Pre-Mortem | 倒推失败 | 死因 → 触发 → 早期信号 → 防死 |
| 目标排序 | 逼取舍 | 目标？排序？冲突时牺牲谁？ |
| 双钻 / 苏格拉底 | 澄清定义 | 你说的 X 指什么？边界？反例？ |
| 类比思维 | 跨域对照 | 参照对象？同构点？不可照搬处？ |

**领域维度模板**（命中即用，须说明匹配理由；未命中就地生成并回填）：

| 任务类型 | 领域维度 |
|---|---|
| 技术架构 / Agent 记忆 | 场景·频率｜技术栈｜生命周期｜数据类型｜规模·吞吐｜正确性校验｜部署·隐私·合规｜时延·成本｜写入变更·可解释性｜结构化·冲突处理 |
| 知识沉淀 / 知识管理 | 激励与回报｜写→读→用闭环｜入口与检索｜维护责任｜载体形态｜三断点(没人写/写了没人看/搜不到) |
| 通用产品 / 功能 | 用户·场景｜痛点｜成功指标｜约束｜竞品·替代｜风险·失败模式 |
