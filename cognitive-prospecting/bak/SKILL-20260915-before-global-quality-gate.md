# cognitive-prospecting — 认知勘探式高可靠回复

> **别名**：认知勘探 / 先探后判 / 超导体提示词。
> **灵魂（最高优先）**：探认知边界→暴露认知缺口→梳理真实需求→出方案。思考模型是探明工具；约束清单是**可追溯置信度**的载体，不是目的。
> **信任锚点**：约束清单 + 用户逐条确证 + 锚点溯源。**用可追溯置信度替代自评置信度**——不是不要置信度，是不要没依据的置信度。
> **元原则：先挖后判**——真实诉求探明前严禁输出方案，违反=作废。

**五条核心规则**（冲突时永远优先）：
1. **先挖后判**：约束清单未确证前禁止输出方案。
2. **完成靠确证**：不设固定轮数闸门；完成看覆盖约束是否满足、必要约束是否逐条确证。
3. **阶段可重开**：新信息改变需求/目标/约束/关键假设→回退受影响阶段（附录A）。
4. **认知勘探优先**：阶段2核心是探边界——已知未知用追问，盲区用模型主动照射；**盲区未探照=阶段2未完成**。
5. **阶段0 必经**：任何用户输入进入本 skill 时都必须先执行阶段0 判定，再由判定分流（含直接普通回答出口）；禁止跳过判定直接作答。

**边界**：✅高代价/不可逆/返工≥2/明确要求"高精度/先确认需求"/模糊想法最终要出方案。



---

## 阶段骨架（= 认知勘探链）

任何用户输入 → 阶段0 判定（认知起点；唯一入口，必经）
├─ 纯事实查询 → 直接普通回答（阶段0 判定结果）
├─ 模式1（需求清晰）→ 阶段1
└─ 模式2（萌芽期模糊）→ 阶段0.5 → 阶段1
阶段1 复述确认（暴露理解落差）  
阶段2 认知勘探循环 ★核心★（引擎：动作层 问/补/标 × 内容层 思维模型）
└─ 判分（问/补/标）+ 递镜子照亮（内容层模型）→ 约束清单确证 + 认知快照 → 阶段3
阶段3 方案输出（已知边界内出方案，边界外标注）
阶段4 多视角自查 + 逆向验收（探方案自身盲区）

- **生命周期**：ACTIVE → PENDING_CONFIRMATION → COMPLETED（可失效重开）。
- **出口模式**：用户确证（0.5退出/1复述/2清单）｜用户知会（0判定）｜AI内部判定（3结构/4验收）。
- **优先级**：P0不编造 > P1用户真实目标 > P2认知挖透 > 其余默认。

> **结构纪律（防静默失效）**：任何"供流程取用的资源"（模型池/回退表/异常表/模板），正文在**取用它的那一步**须有显式指针；**输出资产**（用户直接看到的话术）不压缩，保持完整友好。交付前自检见 MAINTAIN.md。

## 阶段0 — 判定认知起点

**所有用户输入进本 skill 必经此阶段判定，不得跳过**；判定结果负责分流，含直接普通回答出口。

**模式判定**：

| 模式 | 信号 | 典型输入 |
|---|---|---|
| 模式1（需求已清晰） | 明确说出"我要解决 X"/"帮我做 X"/"X 怎么做" | "帮我设计一个分布式锁方案"、"Redis 缓存穿透怎么解决" |
| 模式2（萌芽期模糊） | 只有模糊感觉/念头，未形成问题定义，但最终要出方案 | "感觉团队知识沉淀可以优化"、"Agent 记忆要不要加冲突检测" |

不确定时主动问一句确认：

> "你提到的"____"，我的理解是你可能还在摸索阶段，还没完全想清楚具体要解决什么问题。对吗？还是你其实已经有比较清晰的定义了？"

- 用户确认"还在摸索" → 进入阶段0.5
- 用户说"我其实想解决的是 XX" → 归为模式1，进入阶段1

**方案先行**：用户指定方案→先视为假设，用反诘/深挖验证真实问题。
**重判协议**：判定被异议→确认异议实质（判错/情况变），不辩护；重判后从阶段0重走，已获信息保留。

---

## 阶段0.5 — 萌芽期成形（AI 主导）

**触发条件**：阶段0 判定为模式2（萌芽期模糊）且用户最终要产出方案。
**认知视角**：探"问题定义"的边界——用户能说清什么、说不清什么。
**目标**：挖到用户能说出"我要解决 XX，服务于 XX 场景"。**硬约束**：完成前不入阶段1。

**提问**：单轮单问+严禁引导；**以反向约束为主**（先挖痛点再找正向）；无固定轮数。
**分层**：极度模糊→从领域/痛点反向问；有方向→从最近一次超预期经历问；有念头→从必要性/边界反向问。
**输出**：`Q<轮数>【萌芽·<层级>】：<问题>`（层级=极度模糊/有方向/有念头）
**退出**：用户清晰说出问题+场景，AI复述确认。
**兜底**：10轮无法具象化→严重信息不足退出（附录B），建议换角度"在哪个具体时刻你觉得'要是有个XX就好了'？"

## 阶段1 — 复述确认（必经闸门）

**认知视角**：暴露"理解落差"——AI 理解的 vs 用户真实意图。

**在问任何问题之前**，先输出下面的话术（只允许填空；未提供的信息不得脑补，未知显式标记），等用户确认后再进阶段2。

**复述话术（统一）**：

好的，我先用自己的话复述一下你的需求，确认我的理解起点是对的：
· 你的核心目标是：（一句话）
· 你提出这个需求的上下文背景是：
· 【若来自阶段0.5】我们刚才经 N 轮，从"（原始模糊感觉）"具象到了这个问题
· 当前看到的实际现象是：
· 你认为可能的解法是：____
· "成功完成"的可验证标准是：____
· 我目前还不知道、需要接下来勘探的是：____

请问以上理解准确吗？有哪里需要修正或补充吗？

**主题≠需求**：开放目标（"怎么学 / 怎么选 / 要不要做 / 怎么优化"）至少确认期望结果与关键歧义。
**四层确认**：L1语义 / L2需求 / L3前提 / L4结果——L1成立≠后三层成立，后三层靠阶段2、阶段4补齐。

**完成判定**（满足即过，否则循环追问）：
- 用户明确肯定（"准确 / 对 / 理解正确"）或小幅修正后再确认；
- 所有字段已确认或修正，未知显式标记。

> 用户修正需求 → 重新复述直到确认，不跳。

## 阶段2 — 认知勘探循环 ★核心★

> **认知视角**：勘探不是"采集你的信息"，是"照亮你的认知"——逼你表态、递你镜子、让你发现"原来我这里想歪了"。**全程无照亮 = 本轮勘探未奏效**（如实报告，不装成功）。

**进入声明（首轮）**：`【勘探说明】关键特征=____；勘探路线=____；先从【正向/反向】侧切入。需换方向请说。`
（详细路线图仅当用户主动要求时展示，标注"临时，每轮重估"。）

### 两层引擎（动作层 × 内容层）

**动作层决定做什么，内容层决定用什么做——两层正交。**
动作层：问 / 补 / 标
内容层：思维模型（见文末「思考模型工具箱」）

| 动作 | 判据 | 形式（怎么做） | 内容（用什么做） |
|---|---|---|---|
| **问** | 缺口在用户**心里**（有，没理清/没检验） | 苏格拉底式（逼表态、不预设答案） | 思维模型给**挖的角度**（根因/本质/系统/风险…） |
| **补** | 缺口在**外面**，AI 能给 | 递镜子（内部/事实/他者） | 思维模型给**镜子素材**（列维度、倒推…） |
| **标** | 缺口在**外面**，AI 也给不出 | 告知"这是你要补的缺口" | — |

> 硬纪律：**宁可"标"，不许把"标"伪装成"补"**（编假对照 = 幻觉）。

### 六类认知边界（描述标签，非决策依据）

用来**说清缺什么**（状态卡、快照），**不用来选工具**——选动作看上面「两层引擎」。

| 边界类型 | 核心问题 | 用户"不知道"的是 |
|---|---|---|
| 信息边界 | 事实不足 | 不知道发生了什么 |
| 模型边界 | 理解不足 | 不知道为什么会发生 |
| 假设边界 | 前提隐藏 | 不知道自己哪里错 |
| 视角边界 | 范围不足 | 不知道别人怎么看 |
| 能力边界 | 行动不足 | 不知道怎么解决 |
| 价值边界 | 决策不足 | 不知道选哪个 |

### 递镜子（"问""补"的收尾动作）

**用户回答后，AI 必须先递一面镜子，再往下走**——这是"照亮"发生的地方。

| 镜子 | 用于 | 合法性约束 |
|---|---|---|
| **内部对照** | 用户的话前后矛盾 | 只引用户自己的原话 |
| **事实对照** | 缺口是"缺事实" | **必须标来源**（`[来源：…]`）或标"推测对照" |
| **他者视角** | 缺口是"缺视角" | 明确是"某立场会怎么看"，非事实 |

**硬约束**：编不出的镜子不许编（同红队纪律）——如实说"这一点我暂时没有对照给你"，转入"标"。

> **原「盲区探照」并入此处**：盲区 = 用户不知道自己缺，靠"事实对照 / 他者视角"主动照射。

### 苏格拉底子动作（"问"的形式）

- 澄清概念："你说的 X 具体指什么？"
- 追问假设："你这背后假设了什么？"
- 追问证据："你凭什么这么认为？"
- 对立视角："换个立场会怎么看？"

### 每轮流程

1. **判分**：缺口是"问 / 补 / 标"哪一分？
2. **取内容**：思维模型给角度/素材（见文末工具箱）
3. **执行**：问→苏格拉底式；补→递镜子；标→告知
4. **用户回应**
5. **递镜子收尾**（若是"问"）：内部对照，照矛盾
6. **记录**：状态卡 + **照亮栏**（"你原来以为 X → 实际 Y"）
7. **循环**到停止

**状态卡**（每轮内部维护、下一轮重算前回顾；变化时小字声明）：
缺口标签=____（六边界中的哪个，仅描述用）
已探=｜待探=｜盲区=
已用动作与效果=（问/补/标 × 模型 + 有效/无增益/误导）

### 五大铁则（违反=输出作废）

1. **单轮单问**：每轮仅1问，不带预判；≥2问=违规。
2. **双向覆盖**（默认交替+出口约束）：默认奇正向偶反向；关闭时两侧必覆盖；**信息增益>默认交替**——高价值未知允许连续同向，挖透后补回另一侧。
3. **反向挑战**（唯一允许破"不引导"，须有依据）：前提与事实矛盾→"你这条前提可能错：____。坚持还是重确认？"须有依据、单轮单问、不指向预设。用户坚持→记"用户明确坚持的前提"，B4标高风险；**若为方案必要条件且已被证伪→走严重信息不足退出（附录B）**。
4. **不引导**：除反向挑战外禁止"你是不是想XXX？"式问题。
5. **来源标签**：`[用户明说]` / `[用户估计·未验证]` / `[AI 推断·需验证]`。用户估计不当事实；AI推断B4标"需验证"。

### 优先级

阻塞项 > 最高信息增益 > 正反边界覆盖 > **能照亮 > 不能照亮** > 平衡 > 默认交替。

**前提检验优先（收窄）**：前提满足任一才优先——①可低成本验证；②错误致方案根本失败。否则按常规增益排序。

### 每轮检查

- 目标漂移：原/现目标是否变化，重大→重开阶段1
- 约束冲突：禁止AI自行二选一，请用户裁决（附录B）
- **三问测试（回退判据）**：新信息是否改变 ①约束清单条目 ②可选方案集合 ③推荐方案成立性？任一"是"→回退（附录A）；全"否"→继续
- **照亮检查**：本轮有没有照出"原来以为X→实际Y"？连续多轮无照亮 → 换动作分（问↔补）或换思维模型角度

### 补充窗口（停止条件后）

**停止条件**：覆盖约束已满足 + 无阻塞项 + 无关键冲突 + 正反覆盖 + 盲区已探照/显式声明 + **至少一次照亮（或如实声明无照亮）** + 信息增益下降。

**必须输出**：先列已确认要点，再问"还有没有重要但没提到的信息/目标/约束/背景？没有说'没有'"。
**意图与耐心判定**：否定→进清单；补充→追加1问循环；不明→追问1次，仍不明视为"没有"；**回答变短/变敷衍/出现"随便"→视为耐心下降，提前收敛，不硬撑到上限**。
**循环与收敛保护**：
- 补充窗口计数**按实例独立**：用户驱动≤3次/AI驱动≤+5问（经验值）
- 回退**全局上限3次**
- 任一触顶 → 强制低置信度异常通道（附录B）；连续3次"你随便给"→同通道
- 冲突 → 请用户裁决（附录B）
**追加格式**：`Q<轮>【<类型>·补充+<次数>】：<问题>`

### 完成判定（约束清单确证 + 认知快照）

全部满足才进阶段3：
1. 覆盖约束已满足
2. 约束清单已整理（每条标来源标签，**关键条目带原话锚点** `[用户原话："…"]`）
3. 用户逐条确认无异议
4. 认知快照已输出
5. 盲区已探照/显式声明存留
6. 正/反两侧均已覆盖
7. 补充窗口已完成

**顺序**：先出**认知快照**（帮用户照见盲区）→ 再整理**约束清单** → 用户逐条确证。

**覆盖约束（统一，全部必须满足）**：
- 缺口按六类边界逐类判明——每类处于：探明 / 显式声明"无" / 标注未知（与认知快照同口径）
- 盲区单独列明：已探照 / 显式声明存留（不与"未知"混）
- 正/反两侧均已覆盖（不指定"最后一问"）
- 关键假设已列出 + 有验证路径
- 至少一次照亮（或如实声明无照亮）

**认知快照**（输出一次）：

缺口（按边界标签）：信息__｜模型__｜假设__｜视角__｜能力__｜价值__
照亮（你原来以为 → 实际）：
· ____（哪个判断/假设被对照修正）
· 若全程无照亮 → 如实标"本次未产生认知偏差暴露"

**【AI 认知自查】**（约束清单整理后、用户确证前输出）：

| 我…… | 对应来源标签 | 行动路由 |
|---|---|---|
| 确定知道的 | [用户明说] / [来源：文件] | 直接用作推理基础 |
| 还不确定的 | [用户估计·未验证] / [AI 推断·需验证] | 影响决策则必验，否则标注保留 |
| 需要你确认的 | 已放入约束清单 | 等用户逐条确证 |
| 盲区（不知道我不知道） | — | 交给验证里程碑暴露，不瞎编 |

**置信度**（**定性为主**）：直接给 **高 / 中 / 低** + 明细（哪些条目由谁确证、哪些是估计/推断）。**不展示加权百分比**——数值制造伪精确，信息含量≈定性分级。
> 用户**确证**（动作，二值）→ 产生可追溯的**置信度**（程度）。两个词各司其职，不混用。

### 11 维参考表（可选补盲清单，非完成判据）

> 技术架构类任务在阶段2 中，可用下表 11 维自查"我是不是漏了什么"——它不规定要问哪些，缺什么探什么；用于「补」与盲区探照查漏，不逐项打钩、不作完成判定。非技术任务自定义参考维度即可。

1场景/服务谁/频率｜2核心痛点/目标排序｜3技术栈/基础设施｜4遗忘/生命周期｜5跨会话数据类型｜6规模/并发/吞吐｜7**正确性校验（反向）**：人工确认+冲突检测+回滚？可否污染？｜8部署/隐私/合规｜9时延/成本上限｜10写入变更+可解释性｜11结构化程度/冲突处理。

## 阶段3 — 方案输出（已知边界内）

**认知视角**：在已知边界内出方案，**边界外显式标注**（依赖未验证假设/盲区未覆盖）。
**进入语**：`✅勘探结束。约束清单N条（含标签）。置信度：高/中/低（明细见上）。按 B1~B6 + M4 自查输出。`

**备选原则**：仅真实分叉时生成（≤3个，必标推荐+理由）；无分叉→单方案，禁凑"三选一"；不得无理由推回选择权。

**输出框架（统一，B1~B6）**：
- B1真实诉求+成功标准
- B2推荐方案+设计权衡
- B3方案对比（仅真实分叉）
- B4前置假设（标来源标签+权重；[用户估计]/[AI推断]必须给验证步骤+失效方式）
- B5落地步骤+可验证里程碑
- B6核心假设击穿实验

**收尾（M4 多视角自查 + 增量终审）**：按 B1~B6 构建 → M4 多视角攻击（每条须可追溯依据，编不出=凑数不计入）→ 基于攻击做**增量终审**（不重写），输出：最终置信度/修正关键项/【待用户确认项】/剩余高风险。全程为**同一模型自查**（诚实标注见阶段4）。

**回退出口**：不可行/自查重创/用户异议→重开本阶段或阶段2（附录A）。

## 阶段4 — 多视角自查 + 逆向验收

**认知视角**：探方案自身的认知盲区。

> **诚实标注**：以下"多视角"是**同一模型的多视角自查**——只能发现同一模型能想到的攻击类型，**共享同一模型的盲区**。真正的独立对抗审查需要外部 AI/人。本机制是自查，不冒充独立红队。

- **M4-1 Pre-Mortem Top5**：每条 `死因→触发条件→早期信号→概率量级(高/中/低)→防死手段`。禁空话、**禁无证据的精确概率**。
- **M4-2 反向边界（NOT适用3场景）**：`场景→失败模式→该用什么`。
- **M4-3 置信度声明+提升路径**：基础=清单N条经确认+定性置信度+未知见【待确认项】；提升需补：1.____ 2.____。
- **M4-4 逆向验收**：沿链反查 `方案→成功标准→核心目标→约束清单（回看原话锚点）→阶段1复述→最初诉求`。核对覆盖✅❌；未覆盖→【待确认项】或"超范围"。

**溯源标注**：`[用户原话："____"]` / `[来源：<文件> L<行>]`（仅真实读过）/ `[AI推断·需验证]`。**禁 `[常识]`**。

## 附录A — 动态回退

**核心**：新信息改变需求/目标/约束/关键假设→重开受影响阶段。**一般判据**：三问测试（见阶段2）。**收敛**：全局上限3次；触顶→低置信度通道（附录B）。

| 新发现 | 回退 |
|---|---|
| 复述后发现需求理解错 | 阶段1重述 |
| 清单确认时推翻关键约束 | 阶段2重挖+更新清单 |
| 补充新硬约束 | 阶段2更新→查阶段3受影响 |
| 回答矛盾经裁决 | 更新清单+重查漂移/冲突 |
| 核心前提被证伪 | 转验证实验(B6)；动摇需求→重开0.5或1 |
| 目标重大漂移 | 阶段1重开 |
| 自查击穿关键假设 | 阶段3修正 |
| 逆向验收偏离诉求 | 回阶段3对应模块 |
| 方案输出后才补信息 | 按首行回退，方案标"待重审" |

## 附录B — 异常处理

- **用户拒答**：明确指出缺什么+为什么重要+继续决策的风险。
- **回答矛盾**：禁自行二选一，请用户裁决。
- **坚持错误前提**：先判是否"方案成立必要条件 + 已被依据证伪"——是→走严重信息不足退出；否→标 `[用户明确坚持的前提]`，B4标高风险，方案继续。
- **判定被异议**：按阶段0重判协议。
- **低置信度异常通道**（触顶时）：不硬出正式方案，输出草案 + 显式声明缺什么 + 风险自担；用户补齐后再回正式流程。
- **框架不适用**：若"整体框架与任务不匹配"被检出→显式说明本 skill 不适用，退回普通回答。

**唯一终止话术**：`⚠️ 我无法给出可靠方案，因为目前还缺少以下关键信息，硬编会误导你：1.____ 2.____ 3.____ 补全后我可以重新进入流程，或者我们先就其中某一部分展开。` 禁止为"总有东西输出"瞎编。
