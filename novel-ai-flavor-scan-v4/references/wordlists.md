## 三、使用规则

| 表 | 统计口径 | 误判排除 |
|---|---|---|
| 套词表 | 单篇内部频次与分布密度（P4 单篇盲读原则） | §9.3：翻译腔、类型套路、古典文体等 |
| 关联词表 | 单篇内部占比；R2 阈值触发须标注来源 | B007：起点/晋江早期网文、青春文学本就高频使用 |

- 两张表均**只作正奇信号**，单点命中不得定罪；
- 词表内部分词为正常文学用词（见 SKILL.md §16.2），须配合频率、分布与耦合判断。

## 四、统计建议（可程序化）

词频统计属确定性任务，优先用脚本而非 LLM 人肉计数：

```bash
# 词表匹配计数示例（Python 环境）
python -c "
import sys, collections
words = open('references/wordlists.md', encoding='utf-8').read()
# 按行提取代号表内容后逐词 count
"
```

> 若输出占比触发 R2 阈值（冗余修饰句 >15% 等），须在报告中注明**统计方式**（脚本/人工估算），人工估算须标注 `[估算·需验证]`。
