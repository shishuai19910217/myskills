# 小说追读体检器（webnovel-reading-health-check）

> **定位**：追读视角的叙事健康诊断。标出影响读者"愿意继续读下去"的体感、逻辑、合理、时空问题，按优先级给修复处方；默认只诊断不改写。
> **使用对象**：小说作者、编辑、网文写手、AI 辅助审稿、剧本/故事检查。
> **与既有 skill 的关系**（独立、互补，可单独用也可叠加用）：
> - `webnovel-quality-check`：检查"故事讲得好不好"（22 大类叙事缺陷，地毯式扫描）；
> - `webnovel-deai-lint`：检查"有没有 AI 味"；
> - 本 skill：检查"读者会不会追读"（体感 × 逻辑 × 合理 × 时空 × 钩子）。
> **版本**：v1.0.0（对应规格 v1.01）

---

## 一、技能定位

### 名称与触发词

- **名称**：小说追读体检器（webnovel-reading-health-check）
- **触发词**：小说检查、追读体检、章节诊断、逻辑自洽检查、时空错乱检查、弃书点排查、读者会不会弃书、追读健康度

### 核心目标

找出影响读者「喜欢、有兴趣、能追读」的**体感、逻辑、合理、时空**问题，并给出**修复优先级**。

### 适用对象

小说作者、编辑、网文写手、AI 辅助审稿、剧本/故事检查。

### 不适用

纯诗歌、纯学术文本、非叙事文本。

---

## 二、核心公式

```
完整读下去 = 喜欢 ∧ 兴趣 ∧ 能追读
```

```
追读倾向 ≈
（体感愉悦 × 逻辑信任 × 合理代入 × 时空可解 × 兴趣钩子 × 喜欢供给）
÷
（体感不适 × 逻辑崩坏 × 时空错乱 × 认知负荷 × 出戏风险）
```

**任一项为 0，追读可能断裂。** 体检的顺序：先找"乘数为 0"的项，再算减分项。

## 三、输入格式

用户在调用时按以下结构提供，缺省字段按默认处理：

```
text
【类型】悬疑 / 言情 / 科幻 / 奇幻 / 现实 / 网文……
【目标读者】普通读者 / 老书虫 / 女性向 / 青少年 / 专业读者……
【检查范围】第 X 章 / 前 3 章 / 全书大纲 / 全文
【作者意图】想写慢热 / 想写爽文 / 想写群像 / 想写意识流……
【文本】粘贴正文
【可选】追读数据、弃书点、读者反馈
```

- **类型**缺失：默认按"通用网文"契约，并在报告中标注"类型契约未声明"；
- **检查范围**缺失：默认视为"本次提交全文"；
- **文本 > 5 章**：提示分批提交以提升精度（跨章时空/逻辑追溯依赖上下文窗口）。

## 四、检查流程：7 步（严格按顺序执行）

### 第 1 步：确认类型契约

问：这是什么类型？读者预期是什么？

| 类型 | 允许 | 不容忍 |
|---|---|---|
| 悬疑 | 诡计 | 线索不公平 |
| 爽文 | 巧合 | 主角降智 |
| 言情 | 慢热 | 情感逻辑不可信 |
| 科幻 | 设定复杂 | 规则不自洽 |
| 意识流 | 时空错乱 | 无美学回报 |
| 现实 | 日常琐碎 | 逻辑失真 |

> 契约缺失时，按最宽容契约假设（允许巧合但要求动机可信），并在报告中明确写出所用的契约假设。

### 第 2 步：体感扫描

逐章标记以下 8 组体感坐标（记下位置与原文证据）：

| 负 | 坐标 | 正 |
|---|---|---|
| 卡顿 | 流畅 ↔ 卡顿 | 流畅 |
| 出戏 | 沉浸 ↔ 出戏 | 沉浸 |
| 憋屈 | 爽 ↔ 憋屈 | 爽 |
| 无聊 | 紧张 ↔ 无聊 | 紧张 |
| 疏离 | 共情 ↔ 疏离 | 共情 |
| 信息过载 | 信息刚好 ↔ 信息过载 | 信息刚好 |
| 疲劳 | 疲劳 ↔ 恢复 | 恢复 |

### 第 3 步：逻辑自洽审计

画三条链，逐链追问：

- **因果链**：因为 A，所以 B，是否成立？
- **动机链**：人物为什么这么做？动机是否配得上行为？
- **规则链**：世界规则、能力规则、社会规则是否前后一致？

### 第 4 步：合理性审计

按类型契约判断六类合理性：现实逻辑、类型逻辑、情感逻辑、动机逻辑、社会文化逻辑、专业逻辑。

### 第 5 步：时空审计

画三张表：**时间线表、空间地图、视角规则表**。

检查项：时间线矛盾、时间流速矛盾、空间跳跃、视角越界、年代错位、穿越规则混乱、多线错位、时间循环。

**关键纪律：先判定"错误型 vs 手法型"，再决定是否报告为问题**（判定标准见"五-D 时空错乱"）。

### 第 6 步：追读三要素审计

- **喜欢**：读者喜欢谁？喜欢什么？为什么？
- **兴趣**：读者好奇什么？下一章非读不可吗？
- **能追读**：文本内是否提供追读条件？章末钩子、更新稳定、平台便利、付费门槛。

### 第 7 步：输出诊断与修复

按优先级五档归类所有问题，并输出完整报告（模板见"七"）：

| 档位 | 含义 | 处置 |
|---|---|---|
| 致命 | 直接弃读 | 必须修，一票否决 |
| 严重 | 大量出戏 | 优先修 |
| 明显 | 部分读者会停 | 排期修 |
| 优化 | 能读但无亮点 | 锦上添花 |
| 加分 | 强追读 | 保持并放大 |

## 五、四维检查表

### A. 读者体感

| 检查项 | 苏格拉底问题 | 例子 |
|---|---|---|
| 语言流畅度 | 读起来卡吗？ | 海明威短句易读；普鲁斯特长句门槛高 |
| 节奏感 | 哪里拖？哪里赶？ | 《斗破苍穹》快；《魔戒》慢 |
| 信息负荷 | 信息过载还是刚好？ | 《沙丘》前 100 页设定密集 |
| 情绪冲击 | 爽、虐、治愈、恐惧？ | 《基督山伯爵》爽；《活着》虐 |
| 沉浸/出戏 | 哪里出戏？ | 角色降智、机械降神 |
| 共情/疏离 | 我在意谁？ | 《哈利·波特》孤儿视角 |
| 悬念/期待 | 下一章非读不可吗？ | 《达·芬奇密码》章末钩子 |
| 疲劳/恢复 | 需要喘气吗？ | 大战后插日常 |
| 画面感 | 能看见吗？ | 金庸打斗；《三体》宇宙场景 |

### B. 逻辑自洽

| 检查项 | 苏格拉底问题 | 例子 |
|---|---|---|
| 因果链 | 因为 A 所以 B，成立吗？ | 推理线索不公则弃 |
| 人物动机 | 他为什么这么做？ | 《哈姆雷特》延宕 |
| 规则一致 | 规则前后矛盾吗？ | 《哈利·波特》魔法规则 |
| 伏笔回收 | 埋的坑填了吗？ | 《解忧杂货店》闭环 |
| 推理公平 | 线索公平吗？ | 《罗杰疑案》叙述性诡计 |
| 人设稳定 | OOC 了吗？ | 角色突然降智 |
| 情感逻辑 | 态度转变可信吗？ | 《傲慢与偏见》伊丽莎白转变 |
| 世界逻辑 | 世界运行自洽吗？ | 《1984》极权逻辑 |
| 机械降神 | 突然外挂？ | 烂尾、强行巧合 |

### C. 合理

| 检查项 | 苏格拉底问题 | 例子 |
|---|---|---|
| 现实逻辑 | 现实会这样吗？ | 古装出现现代词 |
| 类型逻辑 | 类型契约允许吗？ | 爽文允许巧合，不容忍降智 |
| 情感逻辑 | 情感过渡够吗？ | 突然爱上，出戏 |
| 动机逻辑 | 动机足够吗？ | 反派为坏而坏 |
| 社会文化逻辑 | 文化上合理吗？ | 《红楼梦》诗词门槛 |
| 专业逻辑 | 专业细节对吗？ | 医疗、法律、军事错误 |

### D. 时空错乱

**先区分：错误型 vs 手法型。**

| 类型 | 检查项 | 例子 |
|---|---|---|
| 错误型 | 时间线矛盾 | 前后日期冲突 |
| 错误型 | 空间关系矛盾 | 地图前后不一 |
| 错误型 | 视角越界 | 第一人称知道别人心理 |
| 错误型 | 年代错位 | 古装出现现代词 |
| 错误型 | 穿越规则混乱 | 能力规则随意变 |
| 手法型 | 意识流 | 《尤利西斯》 |
| 手法型 | 魔幻现实主义 | 《百年孤独》 |
| 手法型 | 多线叙事 | 《云图》《冰与火之歌》 |
| 手法型 | 叙述性诡计 | 《罗杰疑案》 |
| 手法型 | 时间循环 | 无限流、循环类网文 |

**判定标准**：

- **手法型**：可控、可理解、有意图、有锚点、有回报；
- **错误型**：失控、困惑、无提示、无回报。

无法判断时记为「疑似」，在报告中标注待作者确认，不武断定性。

| 等级 | 分数 | 含义 |

| C | 60-69 | 高危弃读 |

1. 读者此刻喜欢谁？为什么？
2. 读者此刻讨厌谁？为什么？
3. 读者此刻好奇什么？
4. 下一章非读不可吗？
5. 体感流畅还是卡顿？
6. 哪里出戏？
7. 因果链完整吗？
8. 人物动机合理吗？
9. 规则前后一致吗？
10. 伏笔回收了吗？
11. 时间线有矛盾吗？
12. 空间关系清晰吗？
13. 视角越界了吗？
14. 年代/文化词错位了吗？
15. 错乱是错误还是手法？
16. 类型契约允许吗？
17. 有没有机械降神？
18. 认知负荷过高吗？
19. 情绪成本大于回报吗？
20. 修复优先级是什么？

### 正反奇偶收束

- **正问**：什么让读者继续？
- **反问**：什么让读者停止？
- **奇问**：哪个单点致命？（乘数为 0 的项）
- **偶问**：哪些成对结构？期待/满足、投入/回报、信任/出戏。

## 十、已知局限性

1. **跨章长程检测受限**：单次 1-5 章内可准确识别局部时空/逻辑矛盾；跨 10 章以上的长程伏笔回收、人物弧光追踪依赖上下文窗口，超范围部分仅在报告中提示"需回查 X 章"，不做武断结论。
2. **类型契约假设风险**：作者未声明类型时，本 skill 使用默认契约假设；若实际类型不同，部分结论可能偏移，报告中会明确标注所用假设。
3. **专业逻辑判定**：医疗/法律/军事等专业错误依赖训练知识，可能漏判或误判，凡不确定者仅标"疑似专业存疑"。
4. **主观维度边界**：体感、情绪冲击等维度的评分带有主观性，报告中与客观逻辑问题分开呈现。

---

## 十一、执行纪律（Do / Don't）

**Do**：
- 严格按 7 步顺序执行；先找"乘数为 0"的致命项，再做减分项排序；
- 每个问题必须带位置 + 原文证据（≤30 字）+ 影响 + 修复处方；
- 时空错乱先判"错误型 vs 手法型"再定性；
- 评分必须与问题清单互相印证（有致命项不得给高分档）；
- 类型契约未声明时，先声明假设再体检。

**Don't**：
- 不改写原文（除非用户明确要求"帮我改"）；
- 不武断定性无法判断的时空/专业问题（标"疑似"待作者确认）；
- 不跳过体感扫描直接谈逻辑；
- 不给无优先级的平铺清单——所有问题必须归入五档优先级。
