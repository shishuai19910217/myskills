# 思维模型速查表（十阶段 → 六阶段映射）

> **归属**：`correctness-enhanced-reply` 附录D 外移文件。
> **定位**：**流程级导航 + 统一路由流水线的「阶段过滤」层**：
> - 阶段 2「特征识别路由表」= 特征级（输入 / 回答 / 卡壳信号 → 主/备工具，每轮触发）；
> - 本表 = 阶段级（**推进到哪一步**想起哪个模型 + **允许哪些工具入场**）；
> - 协同方式：特征识别选中的工具，须经本表当前阶段的映射范围过滤后才执行（超出范围 → 推迟到对应阶段）。
>
> 十阶段是通用问题解决流程，本 skill 的六阶段状态机已隐含覆盖它们；下表只做"十阶段 → 六阶段"的映射对照，不另设独立流程。

| 思维模型十阶段 | 核心问题 | 首选模型 | 映射到本 skill 六阶段 |
|---|---|---|---|
| ① 发现问题 | 到底发生了什么？还有什么可能？ | 双钻 Discover / 苏格拉底提问 | 阶段 0.5（萌芽期成形） |
| ② 定义问题 | 我们真正要解决的是什么？ | 双钻 Define / 5W2H | 阶段 1（需求复述确认） |
| ③ 判断认知边界 | 知道什么？不知道什么？哪些只是猜测？ | 认知分类（原"认知四象限"） | 阶段 2（认知分类自查） |
| ④ 找根因 | 为什么会发生？ | 5Why / 鱼骨图 | 阶段 2（动机深挖） |
| ⑤ 找本质 | 哪些是真约束？哪些只是惯例？ | 第一性原理 / 冰山模型 / 系统思维 | 阶段 2（特征识别路由表） |
| ⑥ 生成方案 | 有哪些可能的解决路径？ | 双钻 Develop / 第一性原理 / 逆向思维 / 类比思维 | 阶段 3（方案输出） |
| ⑦ 对抗方案 | 这个方案哪里可能错？ | 红队审查 / 钢人论证 | 阶段 3 角色 2 + 阶段 4（红队/对抗） |
| ⑧ 推演后果 | 做了以后会怎样？再然后呢？ | 二阶思维 / 系统思维 | 阶段 4（Pre-Mortem） |
| ⑨ 决策 | 哪个方案最值得做？ | 决策树 / 成本收益 / 机会成本 / 80/20 | 阶段 3（备选原则 + 推荐标注） |
| ⑩ 结构化输出 | 怎么让别人快速理解并执行？ | 金字塔原理 / 5W2H / MECE | 阶段 3 模板 + 阶段 4 逆向验收 |

> 说明：
> - ③ 的"认知四象限"已在主文正名为「认知分类」（共五类），本表统一用新名。
> - ⑦ 的"钢人论证"已补入「特征识别路由表」（特征：对抗不充分）；它是红队审查的姊妹工具——先为对手方案构造最强版本再攻击，避免只打自己的方案。
