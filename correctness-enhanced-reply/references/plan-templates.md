# 方案输出模板（阶段 3 · A/B/C 完整格式）

> **归属**：`correctness-enhanced-reply` 阶段 3 外移文件。主文保留备选原则与模板骨架；本文件是输出前的完整格式依据——**进入阶段 3、输出方案前必读**。

## 进入确认语

```text
✅ 需求挖掘阶段结束。
以下是经你逐条确认的【约束清单】（共 N 条，含来源标签）。
确证度评分：____%（仅参考，不作准入；明细见上一步）
【元原则声明】基于已确证的约束清单，下面按模板 __（A/B/C）__ 输出完整方案。
```

## 模板 A（轻量）4 模块

```text
【A1 · 诉求重述】____（1-2 句）
【A2 · 推荐方案】____（明确设计权衡：放弃了什么，换来了什么）
【A3 · 快速对抗自查】失败场景 & 规避方案（至少 2 条，具体到触发条件和量级）：1. ____ 2. ____
【A4 · 核心假设击穿实验（1 行）】第一条验证动作：____ ｜ 证伪后回退：____
```

## 模板 B（标准）6 模块强制框架

```text
【B1 · 真实诉求重述 & 成功标准】____（证明真的懂了，不是复述字面需求）

【B2 · 推荐方案 & 设计权衡】____（为什么没选其他自然路径）

【B3 · 方案对比】（仅真实决策分叉时：推荐 + ≤2 备选）
表格维度：适用场景 / 核心优势 / 主要劣势 / 落地成本 / 风险量级 / 确证依据（约束清单哪几条支持）

【B4 · 前置假设与依赖】每条假设标来源标签 + 权重（[用户明说]=1.0 / [用户估计·未验证]=0.4 / [AI 推断·需验证]=0.3 / [沉默默认]=0.1）—— 若不成立，方案失效/降级方式：____。
[用户估计·未验证] 与 [AI 推断·需验证] 的假设必须给出验证步骤，不得当事实用。

【B5 · 落地步骤 & 可验证里程碑】
阶段（n）: ____ → 完成标准：____ → 时间/资源预估：____（列出 1~3+ 个阶段）

【B6 · 核心假设击穿实验】
1. 第一条要做的验证/证伪动作：____（做完前，不要投入大量资源）
2. 若被证伪，回退方案：____
```

> 无真实分叉时：B2 一句话说明"为什么没有备选"（哪个约束使路径唯一），跳过 B3，其余模块不变。

## 模板 C（高压）= 模板 B + 三角色分离

**扮演三个独立角色，角色间严禁信息互串：**

- **角色 1 — 方案构建者**：严格按 B1~B6 输出完整方案，输出完后不加任何自评。
- **角色 2 — 红队审查官**：逐条攻击角色 1 的每一条假设、每一个权衡决策。**攻击只打有真依据的点，不设配额**——找不到就如实说。每条格式：

```text
【攻击 #n：针对假设/权衡 <编号>】
攻击点：____
攻击依据（约束清单哪条 / 用户原话 / 可查事实）：____
结论：该假设【仍然成立 / 需修正为 ____ / 完全不成立】
修正建议：____
```

  **硬约束**：每条攻击必须能追溯到依据；**编不出依据的攻击 = 凑数 = 不计入**。所有"需要用户才知道"的未知**不得内部自改**，一律列入【待用户确认项】。

- **角色 3 — 终审官**：基于原始方案 + 攻击结果输出**最终修正版**（原框架增量修改，不重写），附带：

```text
【最终方案确证度】清单 N 条全部经用户确认；评分 ____%（仅参考）；剩余不确定项见【待用户确认项】
【相比角色 1 初始方案，修正了以下关键项】1. ____ 2. ____
【待用户确认项】（所有需要用户才能知道的未知，逐一列出）1. ____（缺少它影响哪条假设）
【剩余高风险未解决项】· AI 可内部应对：____（风险应对：____）· 必须用户提供：____（已列入【待用户确认项】）
【逆向验收】回到阶段 1 复述 + 约束清单逐项核对：核心目标 / 成功标准 / 清单 N 条 → 是否覆盖 ✅/❌；未覆盖项 → 列入【待用户确认项】
```
